精评

1. 快答模型也得考可靠性：SO-Arena 测了 21 个模型，最强的可靠性只排第 7

2611.15777

一句话：SO-Arena 是首个系统刻画 System One 模型能力谱与决策可靠性的基准——11 个领域、5 类能力家族、21 个模型参评，结论是强整体表现不等于可靠决策，最强的 System One 模型可靠性只排第 7。

贡献/机制：System One 模型承诺无需漫长 token 生成即可快速通用决策，但现有评测多只看聚合分数，看不清能力广度与决策是否可靠。SO-Arena 从两个维度刻画模型：能力谱方面，用可靠来源与人工核验的参考标签做证据锚定评估、按领域定制难度标准做细粒度评估、并在沙箱里做交互式评估（模型迭代执行动作）；推理密集型任务还支持 System One 与 System Two 的对照。可靠性方面，用两项互补度量：受控选项集变化下的决策稳定性、以及无有效选项时的缺失答案识别。作者：Lichen Li、Ziping Dong、Sicheng Feng、Qi Li、Xinchao Wang（5 人）。

数值结果：21 个模型的评估显示，扩展规模与增加推理的收益在不同领域差异很大；最强的 System One 模型整体表现最好，但可靠性排名仅第 7。

批判性分析：这篇的价值在于把评测从“答对多少”推进到“答得有多稳”——选项集一变就改答案、没答案时硬编一个答案，这类毛病在快速决策模型里比在慢思考模型里更危险，而“可靠性第 7”这个反差正好说明聚合分数会掩盖它。但要注意两点：一是摘要没有展开 11 个领域里哪些领域可靠性最差、哪些模型在稳定性与缺失识别上各有什么短板，结论停留在“要同时看两个维度”的层面；二是可靠性度量本身（选项集扰动、缺失答案识别）仍是实验室构造，能否对应真实部署里的决策风险，还需要更多场景验证。

摘要译文：System One 模型承诺无需漫长的 token 生成即可实现快速通用决策。然而，要理解它们的能力谱与决策可靠性，仅看现有基准上的聚合表现是不够的。现有评估往往对模型能力的广度与决策的可靠性洞察有限。我们提出 SO-Arena，一个刻画 System One 模型能力谱与决策可靠性的基准，覆盖 11 个领域与 5 个能力家族。在能力谱上，SO-Arena 通过可靠来源与针对模型可见输入人工核验的参考标签提供证据锚定的评估；通过领域特定的难度标准实现细粒度能力评估；并通过模型在沙箱中迭代执行动作的真实交互评估。推理密集型任务还支持 System One 与 System Two 的比较。除准确率外，SO-Arena 还通过两项互补度量评估决策可靠性：受控选项集变化下的决策稳定性，以及无有效选项时的缺失答案识别。对 21 个模型的评估显示，扩展规模与增加推理的收益在不同领域差异很大。更重要的是，强的整体表现并不必然意味着可靠的决策：表现最好的 System One 模型在可靠性上只排第 7。这些发现共同表明，需要把能力谱与决策可靠性作为互补维度来刻画，从而系统地呈现 System One 模型的优势与局限。

2. 886M 参数的零样本克隆 TTS：ZONOS3-Mini 在 55 个语言集上词错率 6.71%，笔记本可实时跑

2611.16525

一句话：ZONOS3-Mini 是一个超紧凑、超快的零样本声音克隆 TTS 模型——886M 参数、每 token 仅激活 100M，配 15Hz 帧率的新编解码器 ZAC-1，在新基准 ZTTS2-Eval 的 55 个语言集上宏观平均词错率 6.71%，与更大更慢的 SOTA 模型相当。

贡献/机制：模型用一个潜在 MoE 主干（886M 参数，每 token 仅 100M 激活）加新音频编解码器 Zyphra Audio Codec 1（ZAC-1），把 44.1kHz 音频表示为 15Hz 帧率的序列，从而在笔记本或手机上实时运行，同时保持一流的准确率与克隆保真度。权重、推理与训练代码全部公开。作者：Gabriel Clark、Sofian Mejjoute、George Close、Beren Millidge（4 人）。

数值结果：在新基准 ZTTS2-Eval 上，55 个语言集（35 个干净集、20 个野外集）宏观平均词错率 6.71%，与更大更慢的 SOTA 模型相当。

批判性分析：这篇的卖点很实在：MoE 稀疏激活加 15Hz 超低帧率编解码器，把“零样本克隆”从服务器级模型拉到了笔记本可实时运行的量级，而 6.71% 的宏观平均词错率覆盖 55 个语言集、不是只在英语上刷分，说明紧凑化没有以牺牲多语言能力为代价。但要注意两点：一是摘要没有给出克隆保真度的具体数值（只说“与 SOTA 相当”），相似度、自然度这些 TTS 的关键指标得看正文；二是 ZTTS2-Eval 是作者自建的新基准，6.71% 在已有基准上的横向可比性还不清楚。

摘要译文：ZONOS3-Mini 是一个超紧凑、超快的零样本声音克隆文本转语音模型。该模型可在笔记本或智能手机上实时运行。以其延迟与尺寸而言，它达到了最先进的准确率与克隆保真度。为此我们提出一个仅 886M 参数（每 token 仅 100M 激活）的潜在 MoE 主干，以及一个新的音频编解码器 Zyphra Audio Codec 1（ZAC-1），它以 15Hz 的帧率表示 44.1kHz 音频。在新的 ZTTS2-Eval 基准上，ZONOS3-Mini 在 55 个语言集（35 个干净集与 20 个野外集）上达到 6.71% 的宏观平均词错率，与更大、更慢的最先进模型相当。我们发布了模型权重、推理与训练代码。

3. 全双工世界模型来了：Duo 边听边看边回话，意图与实现同为世界的一等公民

2611.15131

一句话：Duo v1 是首个全双工 Reciprocal World Model——持续感知音视频输入的同时实时回应用户，把“意图”（认知的世界交互）与“实现”（连贯的音视频行为）当作构成世界的两块同等基石，而不是把推理当成世界之外的控制器。

贡献/机制：现有世界模型大多只模拟物理现实，把推理与决策当作外部控制。Reciprocal World Model（RWM）把智能与物理现实视为同等根本。Duo v1 有三项关键设计：（1）用自回归建模做持续交互推理与参与决策，而不是只把它当作扩散模型的指令理解；（2）在统一时间线上为 Intent 与 Realization 构建分块条件与同步 token，用模块内与跨块的注意力掩码强制因果依赖、不偷看未来输入；（3）用双重 rollout 蒸馏缓解两个模块的分布漂移——在自回归生成的 Intent token 与 Realization 合成的音视频历史的混合上训练。两个模块持续感知实时音频、视频与文本，支持带打断的自发对话；除对话外，用户还可以分享真实物体、重塑虚拟场景、指挥助手或玩音视频游戏，无需鼠标键盘。作者：Hengyuan Cao、Biao Gong、Guoshan Lu、Qiyuan Zhang、Lin Liu、Yiding Tian、Yilei Jiang、Yuxin Ma（8 人）。

数值结果：摘要未给出基准分数或延迟等量化结果，这是一份以架构与系统设计为主的技术报告。

批判性分析：这篇的立意比“又一个对话模型”大一号：它把全双工交互放进世界模型的框架里，用同步 token 与双重 rollout 蒸馏处理“边听边说”最难的两件事——时序对齐与分布漂移；“意图与实现同为世界”这个提法，也点出了现有世界模型“看得见、想不明白”的短板。但要冷静看：全文没有给出任何量化结果——没有延迟、没有打断处理成功率、没有与现有全双工语音系统的对照，Duo v1 目前更像一个架构宣言而非可验证的系统；“下一版即将推出”的表述也说明这只是第一步。

摘要译文：在本报告中，我们提出 Reciprocal World Model（RWM），并介绍 Duo v1，一个全双工世界模型，在持续感知音视频输入的同时实时回应用户。RWM 把智能与物理现实视为构成世界的同等根本要素。现有世界模型大多聚焦于模拟后者，把推理与决策当作外部控制而非世界本身的组成部分。在 RWM 中，我们识别出两项同等根本的能力：意图（Intent），提供世界交互背后的认知；实现（Realization），生成连贯的音视频行为。为实现这一形式化，Duo v1 引入三项关键技术设计：（1）利用自回归建模进行持续交互推理与参与决策，而不是把它局限于扩散模型的指令理解；（2）在统一时间线上为 Intent 与 Realization 构建分块条件与同步 token，用模块内与跨块的注意力掩码强制因果依赖，防止访问未来输入；（3）通过双重 rollout 蒸馏缓解两个模块的分布漂移，在自回归生成的 Intent token 与 Realization 合成的音视频历史的混合上训练。两个模块持续感知实时音频、视频与文本，实现带自发对话与打断的全双工交互。除对话外，用户可以分享真实物体、重塑虚拟场景、指挥助手或玩音视频游戏，无需鼠标或键盘控制。Duo v1 的发布是我们的第一步，下一版本即将推出。我们期待对这一新兴领域更广泛的探索。

4. 空间听觉的照妖镜：MESH 用近 4 万道题测多接收器听觉，最好的模型距离估计只有 21.90%

2611.16787

一句话：MESH 是首个评估多接收器空间听觉的基准——近 4 万道题、13 项静态与动态定位及空间转录任务，11 个音频模型配置加一个 LM 智能体全军覆没：静态距离估计最好仅 21.90%、动态方向追踪 41.54%，四项转录任务的词错率最低也在 59.15% 以上。

贡献/机制：多接收器环境下的空间听觉要求认出谁在说、在哪、如何移动。现有基准评估空间预测、转录、追踪与分布式语音处理，但很少检验语音信号在接收器与运动中是否始终关联到正确的物理声源。MESH 通过共享声学场景的自我中心视角与 allocentric 视角评估这种关联：自我中心视角用本地录音与对端元数据，allocentric 视角把多个接收器的同步录音合并到同一个 3D 世界坐标系。基准含近 4 万道题、13 项静态与动态定位和空间转录任务，评估了 11 个音频模型配置与一个使用专家工具的语言模型智能体。数据集与评估代码已发布。作者：Wen Wen、Bohan Li、KwanHo Tam、Yu Xi、Jing Peng、Shuai Wang、Kai Yu（7 人）。

数值结果：最佳静态距离估计准确率仅 21.90%、动态方向追踪 41.54%；四项转录任务的最低词错率在 59.15% 至 73.10% 之间。消融显示现有模型尚不能有效利用对端信息，在多说话人与动态场景下尤其吃力。

批判性分析：这篇的价值在于把“空间听觉”从单点定位升级为“跨接收器、跨运动的声源关联”——这是分布式麦克风阵列、会议系统与具身听觉真正需要的量，而 21.90% 与 59% 以上的词错率说明现有音频模型离“听清谁在哪说话”还很远；“模型拿到了分布式声学信息却用不好”这个诊断尤其值得注意，问题不在数据而在利用方式。但要注意两点：一是 13 项任务里静态与动态任务的难度分布不均，最低词错率 59% 以上可能部分来自任务本身的高难度设定，绝对值不宜直接与常规 ASR 的词错率对比；二是只评估了 11 个音频模型配置加一个工具智能体，结论的普适性还需更多模型验证。

贡献/机制：决策模型以类型化输出（如带概率的选项）回答问题，一个模型可以当智能体的演员（选动作）、裁判（评估已做动作）或老师（给每个动作打分、用强化学习教策略）。已有工作主要把它们当演员研究，按行动表现评判其 usefulness。这篇问：一个行动很差的决策模型是否仍能教得好。作者在 ALFWorld 上比较三个决策模型与三个通用 LLM 当演员与裁判的表现，并用 JEV 当老师在 ALFWorld 与 WebShop 上教策略。当演员时，六个模型都会被一个更容易的子目标从必须先做的子目标上拉走；当裁判看到完整轨迹时，同一批模型能给通向该子目标的步骤加分，而且问“每个动作是否有帮助”比问“任务是否会成功”更能区分有用与无用的动作。当老师时，JEV 把 Qwen2.5-1.5B 策略的 GRPO 成功率在 ALFWorld 上从 72.8% 提到 82.9%、WebShop 上从 56.8% 提到 71.4%。代码已公开。作者：Haochen Liu、Qianhao Zhu、Zixuan Wang、Dingming Li、Tongbo Chen、Peng Qiu、Yingqi Qu、Weiming Lu（8 人）。

数值结果：JEV 当老师：ALFWorld 72.8% → 82.9%、WebShop 56.8% → 71.4%。

批判性分析：这篇的洞察很漂亮：行动与评判用的是不同的信息——行动时只能预判后果，评判时能看到后果，所以“演员差”不等于“老师差”；“问每个动作是否有帮助、而非任务是否会成功”这个区分也很实用，直接给出了一种更有效的裁判提问方式。但要注意两点：一是结论建立在 ALFWorld 与 WebShop 两个基准、Qwen2.5-1.5B 一个学生模型上，老师的收益是否随学生模型规模与任务类型变化，摘要没有回答；二是“裁判能分清有用动作”与“老师能提分”之间仍隔着一步——裁判信号的质量如何转化为策略的稳定提升，需要更多消融。

摘要译文：决策模型以类型化输出回答问题，例如带概率的选项，因此一个模型可以当智能体的演员（选择动作）、裁判（评估已采取的动作）或老师（给每个动作打分、以强化学习教策略）。已有工作主要把它们当演员研究，按行动表现评判其 usefulness。我们问：一个行动很差的决策模型是否仍能教得好。我们在 ALFWorld 上比较三个决策模型与三个通用 LLM 当演员与裁判的表现，并用 JEV 当老师在 ALFWorld 与 WebShop 上教策略。当演员时，六个模型都会被一个更容易的子目标从必须先做的子目标上拉走。当裁判看到完整轨迹时，同一批模型能给通向该子目标的步骤加分，问每个动作是否有帮助、而非任务是否会成功，更能区分有用与无用的动作。当老师时，JEV 把 Qwen2.5-1.5B 策略的 GRPO 成功率在 ALFWorld 上从 72.8% 提高到 82.9%、在 WebShop 上从 56.8% 提高到 71.4%。这些结果表明，行动很差的模型仍能教得好，因为事后评判一个动作能揭示行动时必须预判的后果。代码见 https://github.com/ZJU-REAL/decision-agents。

10. 代码搭世界、视频模型只负责渲染？WorldDraft：432 组配对测试说这条路还没通

2611.16217

一句话：WorldDraft 用 432 组严格配对测试检验“代码搭 4D 世界、视频模型只负责渲染”的分工——结论是世界保持与视觉实现存在尖锐的操作张力，草图越丰富反而越损害外观保真，冲突线索下源泄漏最高达 64%。

贡献/机制：多模态编程智能体把 4D 世界构建与视觉生成解耦，让视频模型从世界生成器变成生成式渲染器。可靠的生成式渲染器需要两项互补标准：（1）世界保持——保留给定的 4D 运动学与相机路径；（2）视觉实现——在时间上持续绑定文本指定的目标属性。为评估这一能力，作者提出 WorldDraft 基准：432 组严格配对测试用例、48 个可执行 4D 世界家族、6 类动态挑战；3×3 析因设计正交组合草图粒度（从抽象代理到预演）与外观对齐（从中性到冲突），动力学保持相同。对 12 个代表性模型的评估揭示三点：（1）世界保持与视觉实现存在尖锐的操作张力；（2）更丰富的草图脚手架能锚定结构，却反直觉地损害外观保真；（3）冲突的来源线索触发严重的源泄漏（最高 64%），暴露出脆弱的跨模态解耦。为缓解这些瓶颈，作者提出 WorldDraft-Primer，一种即插即用的视觉提示策略，在冻结的视频渲染器上同时改善两个目标。作者：Zhiyu Hou、Wen-Jie Shu、Harold Haodong Chen、Weilin Ruan、Chenfei Liao、Liuzhou Zhang、Disen Lan、Xiaogang Xu（8 人）。

数值结果：冲突来源线索下源泄漏最高达 64%；基准规模为 432 组配对测试、48 个 4D 世界家族、6 类动态挑战，覆盖 12 个模型。

批判性分析：这篇的价值在于把“视频模型当渲染器”这个听起来顺理成章的分工，变成了一个可测量的主张——而且测出来的结果是反直觉的：草图给得越细，外观反而越差；线索一冲突，模型就把草图里的东西漏进画面。这说明当前的视频模型并没有真正把“世界结构”与“外观属性”解耦，渲染器这个角色还没站稳。但要注意两点：一是 WorldDraft-Primer 的改善幅度在摘要里没有量化，“同时改善两个目标”到底改善多少、是否足以投入使用，得看正文；二是 12 个模型的评估细节（哪些模型在哪个维度上相对好）未展开，结论的颗粒度还比较粗。

摘要译文：多模态编程智能体把 4D 世界构建与视觉生成解耦，让视频模型从世界生成器转向生成式渲染器。这种分工引出一个根本问题：如果代码构建世界，视频模型能否只负责渲染？可靠的生成式渲染器取决于两项互补标准：（1）世界保持——保留给定的 4D 运动学与相机路径；（2）视觉实现——在时间上持续绑定文本指定的目标属性。为评估这一能力，我们提出 WorldDraft，一个包含 432 组严格配对测试用例、覆盖 48 个可执行 4D 世界家族与 6 类动态挑战的基准。在 3×3 析因设计下，WorldDraft 正交组合草图粒度（从抽象代理到预演）与外观对齐（从中性到冲突），动力学保持相同。对 12 个代表性模型的广泛评估显示：（1）世界保持与视觉实现之间存在尖锐的操作张力；（2）更丰富的草图脚手架能锚定结构，却反直觉地损害外观保真；（3）冲突的来源线索触发严重的源泄漏（最高达 64%），暴露出脆弱的跨模态解耦。为缓解这些瓶颈，我们提出 WorldDraft-Primer，一种即插即用的视觉提示策略，在冻结的视频渲染器上持续改善两个目标。WorldDraft 与 WorldDraft-Primer 共同为连接程序化 4D 仿真与视频生成、推进物理可信的生成式渲染奠定了基础。

简报

11. SOAP 优化器也能轻量跑：FOAM 状态减半、跑出 Muon 级墙钟时间

2611.16905

Factored One-sided Adam-Moment（FOAM）是 SOAP 的轻量变体：只做输入侧预条件、去掉输出侧 Kronecker 因子，省掉一次特征分解；再用基于行列统计的因子化 Adam 矩估计替代 SOAP 的稠密旋转二阶矩。在 124M 至 760M 参数的 LLM 预训练上，FOAM 的验证损失追平强 SOAP 与 Muon 基线，优化器状态只有 SOAP 的一半，墙钟时间达到 Muon 级别，并在三倍学习率范围内保持稳健。作者：Jaemyung Yu 等（4 人）。

12. 支持 13 个汉语方言群的 LLM 式 ASR：Hy ASR 3.0

2611.14908

Hy ASR 3.0 是基于 LLM 的自动语音识别系统，支持普通话、英语与 13 个汉语方言群（含粤语），在公开的普通话、英语与粤语基准上综合错误率最低，内部测试集上同样最低，方言识别为第一梯队。除纯音频转录外，它支持热词表、问答对话、摘要等多种外部上下文，还能利用句内上下文消歧同音与近音关键词；长语音、儿童与老年语音、低音量与噪声环境下均保持稳健。作者：Aoxiong Yin 等（8 人）。

13. 单声道双人对话拆成双人音轨：Kezek 短回复保留率 0.83 对 0.69，快 4–5 倍

2611.16933

Kezek 把一段恰好两人的单声道录音拆成每人一条、保持原长与时序的音轨，重叠与“嗯”“对”等短回复留在说话人自己的轨上。做法是两阶段：先由双人语音活动模型（带相位不敏感的说话人指纹）一次性定下“谁在说、谁是谁”，再由条件时域分离器执行该决定，输出恒等于输入。与开源流程 pyannote → DialogueSidon 对比，Kezek 在 Open Yap 测试集上短回复保留率 0.83 对 0.69、未见过的 CallHome 英语电话语音上 0.80 对 0.71，泄漏更少、声道交换更少，速度快 4–5 倍（约 230 小时音频/GPU 小时）。作者：Bagzhan Karl、Alizhan Karl（2 人）。

14. 语音 tokenizer 也会被攻破：小扰动打乱语义编码，拖垮下游 ASR 与 LALM

2611.14929

语音 tokenizer 是 ASR 与大音频语言模型的语音前端，但它在语义层面很脆弱：小扰动就能打乱语义编码过程，严重拖垮下游 ASR 与 LALM。作者提出 T-SemAttack，一种基于语义编码器集成的可迁移语义攻击：联合漂移多个语义编码器的表示空间，在保持感知质量的同时破坏语音的语义内容；并分析了层间表示漂移与跨模型梯度对齐，发现不同替代编码器的输入梯度存在方向对齐，暗示共享的对抗敏感方向是跨模型迁移的关键。加固方案 ROSETok 结合噪声训练与鲁棒语义蒸馏，在 9 个开源与黑盒 ASR 系统、4 个 LALM 上验证了攻击的可迁移性与 tokenizer 的鲁棒性。作者：Zhisheng Zhang 等（8 人）。

15. 118M 参数的紧凑 TTS：RSE-TTS 让生成主干兼任参考语音编码器

2611.15464

RSE-TTS 回答了一个问题：语音生成器能否同时当好声音编码器？它的 Reconstructive Speaker Encoder（RSE）复用预训练自回归 TTS 主干，把参考语音与文本转录联合压缩成 8 个连续向量；共享主干使编码器-生成器参数减少 48%。大规模英语训练得到的 118M 参数生成器，在全部三项英语基准上词错率与说话人相似度双双超过 MOSS-TTS-Nano 的官方克隆模式；配合声学延续，RSE-TTS 接近大得多的系统的说话人相似度，词错率低于受评的 CosyVoice 3 与 MOSS-TTS-Local。作者：Ming Ma 等（8 人）。

16. 让冻结的 LALM 测试时“回听”：DeALR 用声学回溯做测试时推理

2611.15439

大音频语言模型通常只编码一次音频、随后在语言主导的空间里多步推理，难以触及细粒度声学证据。Decoupled Audio Latent Reasoning（DeALR）把测试时推理从文本主导的 deliberation 转向主动的音频隐空间交互：跨度级声学回溯（Span-Level Acoustic Backtracking）沿初始注意力分布动态隔离连续的关键声学片段；解耦音频隐优化（DALO）则用置信度引导的策略梯度，在测试时联合优化思想向量与音频补丁，并在生成文本前恢复未损坏的高保真音频嵌入，消除优化带来的分布漂移。实验显示 DeALR 在置信度校准与推理准确率上持续超过已有测试时优化方法，但摘要未给出具体数值。作者：Haoyu He、Yan Rong、Li Liu（3 人）。
