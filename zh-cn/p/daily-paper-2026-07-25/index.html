🔊 Audio LLM

OmniReasoner: Thinking with Long Audio-Video via Native Tool Use

长音视频推理的难点在于关键证据稀疏且跨模态。OmniReasoner 让模型学会"先全局预览、再按需放大"——用工具调用替代均匀高保真输入。

  • 作者: Yu Chen, Caorui Li, Ziyu Xiong, Yidong Wang, Mingqi Gao, Shuman Liu, Biao Liu, Chunfeng Yang, Anxiang Zeng, Haibo Zhang
  • 来源: HuggingFace Papers（1 upvotes）
  • 链接: arXiv | PDF | 代码
  • 关键贡献: 提出 Thinking with Long Audio-Video 的工具调用后训练框架。模型先构建低成本全局预览，再通过 SFT+RL 学会判断是否、何时、在哪里调用 zoom-in 工具获取局部高保真视听片段。引入 TimeAnchor 机制保证工具时间参数在预览和放大两种采样粒度间往返一致。配套 Temporal Augmented Data Engine 通过视频编辑合成工具调用训练轨迹，避免人工标注。
  • 实验结果: 在全模态和视频基准上同时提升答案准确率和时间定位能力，且高保真计算集中在信息密集区域。
  • 精评: 思路清晰——把"看哪里"也变成模型可以学会的决策，而不是预设均匀高保真。TimeAnchor 解决了一个容易被忽略但关键的工程问题：不同采样率下时间参数的语义不一致。需要关注 zoom-in 工具的延迟成本在实际交互场景中的可接受性，以及全局预览的信息损失边界。
  • 相关技术: long audio-video reasoning, tool-use post-training, zoom-in tool, TimeAnchor, temporal grounding
  • 代码/权重: 已开源
📄 Abstract 中文翻译

长音视频推理对全模态 LLM 来说很困难，因为决定性证据往往稀疏、跨模态，且以均匀高保真输入来保存代价过高。我们提出 OmniReasoner，一个用于"长音视频思考"的工具调用后训练框架：全模态 LLM 通过监督微调和强化学习，学会在回答前决定是否、在哪里调用 zoom-in 工具。OmniReasoner 先构建全流的低成本全局预览，需要时再请求特定时间区间的高保真视听检查。由于模型在工具调用前后观察不同采样粒度——稀疏全局预览和密集局部片段——我们引入 TimeAnchor，使工具的时间参数在不同粒度间保持有效且往返一致。为避免昂贵的区间标注，我们构建 Temporal Augmented Data Engine，通过视频编辑和合成生成工具调用训练轨迹。实验表明 OmniReasoner 在全模态和视频基准上均提升了答案准确率和时间定位，同时将高保真计算集中在信息丰富的区域。

Pushing the Frontier of Full-Song Generation: Hierarchical Autoregressive Planning Meets Flow-Matching Rendering

全曲生成框架：用层次化自回归规划歌曲结构，再用 flow matching 渲染高保真音频，支持词到曲、纯器乐和翻唱三种模式。

  • 作者: Junyu Dai, Xinyue Fan, Weiqin Li, Xiangang Li, Yunjia Li, Bin Ma, Yukun Ma, Chongjia Ni, Yufei Shi, Biao Tian
  • 来源: HuggingFace Papers（0 upvotes）
  • 链接: arXiv | PDF
  • 关键贡献: 提出统一歌曲生成框架，包含语义感知 tokenizer（8-codebook RVQ）、hybird-LM（层次化自回归音频 token 建模）、FullDiT（连续 VAE 潜空间全曲 flow matching）和两级旋律模块（翻唱任务中保持原曲旋律）。后训练用 DPO、GRPO 和 OPD 优化 hybird-LM，用 flow-based GRPO 优化 FullDiT。
  • 实验结果: 在多语言自动基准和 Artificial Analysis Music with Vocals 排行榜上取得竞争力表现。
  • 精评: 把"规划结构"和"渲染音频"分层是合理的工程选择——自回归擅长长程结构规划但不擅长高保真生成，flow matching 擅长连续空间渲染但不擅长长程一致性。不足在于摘要缺少与当前最强音乐生成系统的定量对比和消融分析，也未讨论歌词对齐和节拍控制的鲁棒性。
  • 相关技术: full-song generation, hierarchical autoregressive, flow matching, RVQ tokenizer, DPO/GRPO post-training, cover song
  • 代码/权重: 未提及
📄 Abstract 中文翻译

本文提出一个统一的歌曲生成框架，能够从歌词、文本描述和音乐属性生成高质量全长音乐。该框架支持三种任务：词到曲生成、器乐生成和翻唱生成。架构由四个主要组件组成：语义感知 tokenizer 将音频编码为 8-codebook RVQ token；hybird-LM 基于这些 token 进行层次化自回归音频 token 建模；FullDiT 在连续 VAE 潜空间中做全曲 flow matching，以 codec token、歌词和文本描述为条件；翻唱任务的旋律模块从参考音频中提取并离散化旋律线索以指导生成。后训练阶段使用 DPO、GRPO 和 OPD 作为 hybird-LM 的奖励策略，并对 FullDiT 应用 flow-based GRPO 以提升音乐性和渲染质量。在多语言自动基准及 Artificial Analysis Music with Vocals 排行榜上均取得竞争力表现。

🧠 LLM Training

AREX: Towards a Recursively Self-Improving Agent for Deep Research

深度研究不是搜索更久，而是递归验证：AREX 在内循环收集证据构造临时答案，外循环逐条审计约束并启动定向追查。

  • 作者: Shuqi Lu, Chaofan Li, Kun Luo, Zhang Zhang, Hui Wang, Hongwang Xiao, Zheng Liu, Lei Xiong, Jiahao Wang, Sen Wang
  • 来源: HuggingFace Papers（116 upvotes，今日最高）
  • 链接: arXiv | PDF
  • 关键贡献: 提出 Recursively Self-Improving (RSI) 深度研究 Agent。核心洞察是发现-验证不对称性：发现答案昂贵，但验证候选答案可分解为可处理的约束检查。AREX 内循环收集证据并构造临时答案，外循环逐约束审计、识别未验证声明、启动定向后续研究。学习自主上下文更新工具压缩交互历史，保留已验证证据和未解约束。训练采用 agentic mid-training 和长程 RL，在关键证据获取或错误方向纠正处给予密集奖励。
  • 实验结果: 4B 和 122B-A10B MoE 模型在 BrowseComp、WideSearch、DeepSearchQA、HLE 等基准上大幅超越同规模基线，122B-A10B 可竞争更多激活参数的模型。
  • 精评: 抓住了一个本质洞察——深度研究中验证比发现便宜得多。递归自改进的结构设计也很自然：不是让模型搜索更久，而是让它知道自己哪里不确定并定向追查。上下文压缩工具是长程 RSI 的关键使能器。需关注递归深度上限、每轮审计的计算成本、以及约束间存在依赖时审计顺序的影响。116 upvotes 说明社区认可度很高。
  • 相关技术: recursive self-improvement, deep research agent, constraint-wise verification, context compression, agentic mid-training, long-horizon RL
  • 代码/权重: 未提及
📄 Abstract 中文翻译

深度研究要求 Agent 找到同时满足多重约束的答案。发现这样的答案代价高昂，而验证候选答案通常可以分解为可处理的逐约束检查。这种发现-验证不对称性意味着研究 Agent 不应只是搜索更久，而应递归改进当前答案：验证中间结果，并利用部分验证状态指导后续精炼。我们提出 AREX，一族递归自改进（RSI）深度研究 Agent。AREX 在内循环收集证据并构造临时答案、外循环逐约束审计、识别未验证声明并启动定向后续研究之间交替。为在长程中维持 RSI，AREX 学习了一个自主上下文更新工具，将增长的交互历史压缩为保留已验证证据和未解约束的紧凑改进状态，无需外部模型。我们在已验证合成任务和高质量轨迹上通过 agentic mid-training 和长程强化学习训练 AREX。为缓解长程学习中稀疏最终奖励的问题，我们在获取关键证据或纠正错误研究方向的关键步骤处给予密集奖励。我们实例化了 4B 密集模型和 122B-A10B MoE 模型。在 BrowseComp、WideSearch、DeepSearchQA、Humanity’s Last Exam (HLE) 及其他推理和工具使用基准上，AREX 大幅超越同规模基线，并与使用更多激活参数的模型保持竞争力。

SLAI T-Rex: Full-Parameter Post-training of the DeepSeek-V4 Family on Ascend SuperPOD

在昇腾 NPU SuperPOD 上对 DeepSeek-V4 万亿参数 MoE 做全参数后训练，系统级优化达到 34.22% MFU，并在运筹优化任务上零样本 Pass@1 达 71.81%。

  • 作者: Dongfang Li, Xiaodong Luo, Ruoyu Sun, Xuhui Chen, Linyuan Qiu, Jian Meng, Zhengxuan Lu, Yiting Wang, Yucheng Xie, Tao Guo
  • 来源: HuggingFace Papers（56 upvotes）
  • 链接: arXiv | PDF
  • 关键贡献: 在昇腾 NPU SuperPOD 上完成 DeepSeek-V4 万亿参数 MoE 全参数后训练。分层优化框架覆盖模型级并行、计算-通信编排和底层 kernel 执行。建立面向运筹优化的 CPT+SFT 工作流，结合领域资源和求解器验证的合成优化文档构建 10K 高质量 SFT 样本。
  • 实验结果: MFU 34.22%，较开源基线提升 2.93 倍，训练稳定。专门化模型零样本 Pass@1 达 71.81%，超过 GPT-5.4-Mini 3.98 和基座 DeepSeek-V4-Flash 11.27 个百分点。
  • 精评: 价值双层：系统层面，昇腾 NPU 生态的万亿参数全参数训练实践本身就是稀缺信息；应用层面，把通用大模型专门化到运筹优化领域并有可量化提升，验证了"大模型+领域 CPT/SFT"路线在数学建模类任务上的可行性。不足是未披露训练成本、数据配比细节，以及专门化模型在通用基准上是否有退化。
  • 相关技术: Ascend NPU SuperPOD, full-parameter post-training, MoE, DeepSeek-V4, MFU optimization, operations research, CPT+SFT
  • 代码/权重: 未提及
📄 Abstract 中文翻译

万亿参数规模 MoE 模型的全参数后训练引入了大规模分布式训练的系统级挑战，包括严重的显存压力、未重叠的通信开销和低效的 kernel 执行。大多数大规模 LLM 训练系统围绕 GPU 集群构建，而本报告在昇腾 NPU SuperPOD 上展示端到端优化实践。以 DeepSeek-V4 模型族为目标工作负载，我们开发了覆盖模型级并行、计算-通信编排和底层 kernel 执行的分层优化框架。最终系统达到 34.22% 的 Model FLOPs Utilization (MFU)，较开源基线方案提升 2.93 倍，同时保持训练稳定性。在此优化基础设施之上，我们进一步建立了面向复杂运筹优化（OR）任务的 CPT 和 SFT 工作流，称为 SLAI T-Rex。使用 DeepSeek-V4-Flash，我们开发了面向 OR 的 CPT 和 SFT 数据管线，结合收集的领域资源与求解器验证的合成优化文档。最终数据集包含 10K 高质量 SFT 样本，覆盖四类任务和三种问题表示。专门化模型在被评测模型中取得最高平均零样本 Pass@1 分数 71.81%，分别超过 GPT-5.4-Mini 和基座 DeepSeek-V4-Flash 模型 3.98 和 11.27 个百分点。

K12-KGraph: A Curriculum-Aligned Knowledge Graph for Benchmarking and Training Educational LLMs

从人教版教材构建课程知识图谱，设计五个任务族 23,640 道多选题基准和 7,335 样本微调集，测试 LLM 的"课程认知"能力。

  • 作者: Hao Liang, Qihan Lin, Zhaoyang Han, Xiaochen Ma, Zhen Hao Wong, Meiyi Qiang, Linzhuang Sun, Wentao Zhang
  • 来源: HuggingFace Papers（40 upvotes）
