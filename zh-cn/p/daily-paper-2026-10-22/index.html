精评

1. 跨模态概念神经元：音频和文本在 LALM 里共用一小撮神经元

2610.28189

一句话：LALM 的语言骨干只在文本上预训练过，却能识别情感、性别、所说语言等声学属性——这篇在三个 LALM、四类声学属性上找到同时表征音频与文本的"跨模态神经元"，并用转向与失活干预证明它们不只是相关、还能被操纵。

贡献/机制：检验"共享子空间"假说：识别在音频与文本两种输入下都负责同一概念的神经元（跨模态神经元），度量音频神经元与文本神经元的对齐程度随模型与属性类型的变化；再做因果干预——对这些神经元做 steering（转向）和 deactivation（失活），看预测是否随之改变，以区分"必要"与"可操纵"。作者：Tzu-Quan Lin、Chih-Kai Yang、Yi-Cheng Lin、Hao Tang、Hung-yi Lee（李宏毅组）。

数值结果：摘要以定性结论为主：三个 LALM、四类声学属性上均发现不同程度的音频-文本神经元对齐；因果干预确认跨模态神经元对预测是必要的、且可以被操纵。摘要未给出对齐程度的量化数值、三个模型的具体名单与逐属性结果。

批判性分析：这篇和昨日的 Text Dominance 正好互补：昨天说"信息在 LM 输入处还在、生成时被文本压过去"，今天说"对齐的载体就是一小撮共享神经元"——如果成立，文本主导问题就有了具体的干预靶点（保护或增强跨模态神经元的激活）。方法上因果干预比纯相关性探针扎实。但摘要层面的信息缺口明显：没有量化对齐强度、没有逐模型对照，“不同程度"到底差多少、哪类属性对齐最弱都没说；神经元级分析的结论也高度依赖识别方法本身（阈值、显著性口径），正文需核对。对做 LALM 可解释性与音频信息利用的人，这是今天最值得细读的一篇，但引用时应注明摘要未给量化结果。

摘要译文：尽管语言模型骨干只在文本上预训练，大音频语言模型（LALM）在很大程度上能够识别声学属性，例如情感、说话人性别和所说的语言。然而，音频表征在模型产生文本之前如何（以及是否）与文本表征整合尚不清楚。我们假设存在一个音频与文本表征相对齐的共享子空间。为检验这一假设，我们识别出负责同时表征音频和文本的跨模态神经元。我们在三个 LALM 和四种声学属性类型上发现了不同程度的音频与文本神经元对齐。因果干预——对神经元进行转向和失活——证实了跨模态神经元不仅对预测是必要的，还可以被操纵。

2. TTS 语调转向：旋律住在骨干隐状态里，不在 token 栈第一层

2610.27403

一句话：基于残差向量量化的 TTS 里，英语"核语调”（断言的降调 vs 疑问的升调）到底由哪部分生成、能不能干预控制——交换干预在 CSM 与 S2 两个系统里定位到骨干网络隐状态；用人类模仿样本算出的转向向量能在生成环内把大多数录音推到目标语调，代价只是预测自然度小幅下降。

贡献/机制：先试提示控制：基本失败，只有句末问号是可靠杠杆。再在 CSM 与 S2 上做 interchange intervention（交换干预）：语调由骨干隐状态经深度模型传到波形，token 栈第一层几乎不携带语调。转向有两条路线：用句末句号/问号条件生成的骨干状态做差均值向量——能推语调，但推向断言时音色退化；改用人类模仿理论指定语调（文本无标点）的骨干状态算向量、并在生成环内施加，则在两个系统里都能把大多数录音移到另一条件（即使拟合时不含被转向的说话人），且与标点条件向量在打乱标签零假设之上显著对齐。作者：Juan Pablo Vigneaux、Jennifer Cole。

数值结果：摘要未给出精确比例与自然度分数：仅称模仿派生向量"把大多数录音移到另一条件"（move most recordings），自然度代价为"小幅"；细部发现是边缘音（edge tone）的移动比音高重音（pitch accent）更连贯，目标语调只能选到"大致升/降"的粒度、无法精确选定。

批判性分析：定位结论本身就有工程价值：两级 RVQ 架构里"第一层 token 栈不带语调"意味着靠改第一层 token 做韵律控制是找错了层，骨干状态才是控制面。模仿派生向量绕开标点捷径（模型可能只是学会"问号=升调"的文本关联）也做得干净——用无标点的人类模仿状态拟合、还能跨说话人迁移，是扎实的机制证据。要打折的是控制精度：作者自己承认只能推到"大致升/降"，边缘音动了、音高重音没跟上，说明转向推的是语调的一个子成分而非完整旋律；且全篇结论建立在英语核语调这一窄现象上，对声调语言、长句多短语语调的适用性未谈。对做 TTS 可控生成的人，骨干状态转向值得复现，但别把它当现成的语调控制 API。

摘要译文：基于残差向量量化的语音合成系统常分两阶段生成音频：Transformer 骨干发出每帧 token 栈的第一层，较小的深度模型自回归生成其余层。我们问：这类模型的哪些组件负责韵律语调，更准确地说，负责生成英语核语调（例如区分断言的降调旋律与疑问的升调旋律），以及对这些组件的干预能否用于控制语调。基于提示的控制大多失败；只有句末问号是可靠的杠杆。在 CSM 和 S2 中的交换干预定位了语调：骨干的隐状态通过深度模型把语调带到波形，而栈的第一层几乎不携带语调。用在新材料上以句末句号或问号生成的状态算出的差均值向量来转向骨干状态，能移动语调，但推向断言会使音色退化。改用与人类模仿理论指定语调（其文本不带标点）相关联的骨干状态算出的转向向量、并在生成环内施加，则在两个系统中都能把大多数录音移到另一条件（即使拟合时不包含被转向的说话人），代价只是预测自然度小幅下降。这些模仿派生的向量与由两个标点条件得到的向量之间的对齐，远远超出打乱标签的零假设，因此带标点的提示的骨干状态已经表征了语调。被转向的录音大体上按意图变为降调或升调，但边缘音的移动比音高重音更连贯，且目标语调无法在这一大致倾向之外被精确选定。

3. Beyond Two Tracks：全双工对话数据先解决"音轨别串人"，错误时间从 43.9% 压到 4.1%

2610.27109

一句话：全双工对话建模需要"每条音轨始终是同一个人"的持久分轨数据，但生成式分离恢复出的两条音轨会随对话漂移串人——这篇在扩散生成器之前加一个 184 万参数的说话人锚定路由模块，把错误音轨时间从 43.9% 压到 4.1%，且不重训生成器、不改动重建音频。

贡献/机制：Speaker-anchored routing（说话人锚定路由）：184 万参数的小模块在扩散重建之前，把分离器的粗流匹配到固定的注册身份（enrollment identities）并排序，再由冻结的生成器重建语音。评测在 25 分钟的远程对话上进行，并与"匹配注册的波形重识别"基线对比；另有 margin-gated（间隔门控）验证步骤用于未见过的面对面与电话录音。演示页：https://elpsykongloo.github.io/beyond-two-tracks/ 。作者：Yuxuan Chen、Yang Xiao、Jack Sun、Chak Sun、Brick Li、Sam。

数值结果：路由把错误音轨时间从 43.9% 降到 4.1%，优于匹配注册波形重识别的 6.2%；在单人主导发言的段落优势最大（17.8% 对 28.6%）。固定音轨的活动 F1 从 0.46 升到 0.84，逐块重建质量不变。同一路由器可迁移到未见过的面对面与电话录音；加间隔门控验证后，这些场景的错误音轨时间降到 0.9–1.7%，代价是嵌入 20–36% 的输出（全量重识别则嵌入 100%）。

批判性分析：问题选得准：全双工数据的瓶颈不在分离质量而在"轨的身份一致性"，43.9% 的错误时间说明朴素分离+恢复的产物直接拿去训对话模型会把"谁在说话"学错近一半。解法也克制——生成器冻结、只在前面加小路由模块，重建质量不变这一点有数值背书（逐块质量未变 + F1 大涨）。局限：方法依赖注册身份（enrollment），即必须预先知道每位参与者的声音样本，这对"从普通录音大规模恢复数据"的愿景是个前提约束，开放集多人（3 人以上、未注册者插话）场景未覆盖；评测主体仍是双人 25 分钟远程对话，迁移实验给了错误率但没给 F1。对做全双工语音 Agent 数据的人，这是当前数据流水线里该补的一环；引用 4.1% 时应注明是双人、已注册设定。

摘要译文：语音交互正从轮流发言走向全双工对话，Agent 需要边听边说。学习这种协调需要带有持久的、按说话人解析的音轨的自然对话，而这一数据要求仍难以大规模满足。生成式恢复提供了一条从普通录音出发的路线，但恢复出两条声音还不够：它们的音轨分配会随着对话展开而漂移。我们用"扩散之前的说话人锚定路由"解决这一缺失环节：一个 184 万参数的模块将分离器的粗流与固定的注册身份匹配并排序，然后由冻结的生成器重建语音，无需重训生成器或改动重建出的音频。在 25 分钟的远程对话上，路由将错误音轨时间从 43.9% 降至 4.1%，低于匹配注册的波形重识别的 6.2%，且在一位参与者主导发言时优势最大（17.8% 对 28.6%），同时将固定音轨活动 F1 从 0.46 提高到 0.84，而逐块重建质量不变。同一路由器可迁移到未见过的面对面和电话录音，间隔门控的验证步骤将它们的错误音轨时间带到 0.9–1.7%，同时嵌入 20–36% 的输出，而全量重识别嵌入全部输出。由此恢复出的声音成为全双工对话建模所需的参与者一致音轨。音频示例：https://elpsykongloo.github.io/beyond-two-tracks/ 。

4. EA-SURF：多任务语音 LLM 的取舍别靠手调 loss 权重，沿 Pareto 前沿按偏好采样

2610.27200

一句话：语音 LLM 同时做 ASR、时间戳预测与语音翻译，联合训练的任务取舍由固定 loss 权重决定、跟部署偏好无关——EA-SURF 在训练中跟踪当前模型相对各任务参考点的表现、自适应调整标量化权重，在六个三目标请求上把含端点的归一化超体积比固定权重提高了 17.8%。

贡献/机制：端点锚定的偏好感知均匀采样（Endpoint-Anchored Preference-Aware Sampling Uniformly along the Pareto Front）：一种先验（a priori）方法，保留标准加权损失训练流水线，只把标量化权重改成动态量——按当前模型相对每个任务专用参考点的表现持续调整，使最终取舍对准期望偏好。理论上证明在可检验的正则条件下，更新会在目标处驻定、能匹配期望偏好。作者：Liuyuan Jiang、Vishal Sunder、Samuel Thomas、Brian Kingsbury、Jeff Kuo、Lisha Chen、George Saon（IBM 语音组）。

数值结果：在六个三目标语音 LLM 请求上，EA-SURF 经验上收敛到所请求的目标，并把含端点的归一化超体积（endpoint-inclusive normalized hypervolume）相对固定 loss 权重提高 17.8%。摘要未给出各任务（ASR WER、时间戳、翻译）的绝对指标与逐请求偏差。

批判性分析：多任务语音模型的"权重调参"是真痛点：固定权重下最终模型落在 Pareto 前沿的哪个点基本靠运气加试错，把"期望偏好"做成训练时的显式输入、并给出驻定性证明，比事后扫权重网格便宜得多，也更可复述。需要留意：17.8% 是超体积这一聚合指标，超体积变大不等于每个请求都精确命中偏好点，逐请求的命中偏差摘要没给；基线只有"固定 loss 权重"一种，与事后多目标方法（如逐偏好重训、梯度手术类方法）的对比缺席；三目标都来自同一组作者设定的请求，任务再多（如加 TTS、情感）时权重动力学是否稳定未知。对做多任务语音训练的人，这篇的价值在"偏好可编程"这个接口，落地前先看正文里的逐任务绝对数。

摘要译文：语音大语言模型（LLM）执行多项任务，包括自动语音识别（ASR）、时间戳预测（TS）和语音翻译（ST）。语音 LLM 的联合训练会产生任务间的取舍，而使用固定损失权重的标准训练通常无法按照部署偏好控制最终的取舍。为解决这一问题，我们提出端点锚定的偏好感知 Pareto 前沿均匀采样（EA-SURF），一种先验方法，它调整标量化权重，使最终的任务取舍反映期望的偏好。EA-SURF 保留标准的加权损失训练流水线，跟踪当前模型相对每个任务专用参考的表现，并随训练推进调整标量化权重。我们从理论上证明 EA-SURF 能匹配期望偏好，且在可检验的正则条件下更新会在目标处驻定。在六个三目标语音 LLM 请求上，EA-SURF 在经验上收敛到所请求的目标，并将含端点的归一化超体积相对固定损失权重提高了 17.8%。

5. SMART：ASR 评测别再只数词错——按语义后果给错误分段打分

2610.27820

一句话：WER 把所有词级编辑等价对待，但改错一个否定词和漏一个语气词的后果天差地别——SMART 把参考-假设差异映射成语义连贯的片段、用带上下文量规打后果标签，相对人工多数票标签拿到 0.843 F1（直接让 LLM 判断只有 0.745），并给出语义影响错误率 SIER 与基于量规的定向纠错。

贡献/机制：把 ASR 语义评测形式化为"上下文感知的片段级后果评估"：先将参考与假设之间的差异映射为连贯片段，再用结构化上下文量规（rubric）赋予显式后果标签；标签支撑 SIER（语义影响错误率），可在话语、块、词三个层级量化有后果的错误。纠错侧另设一套无目标参考的量规，只用目标假设及其周围的 ASR 假设来指导修正。作者：Xiaoyu Gu、Chencheng Wang、Fuyang Li、Yu Xi、Tao Liu、Jiaoqi Guo、Kai Yu（上海交大）。

数值结果：相对多数票人工标签，SMART 达 0.843 F1，直接 LLM 判断为 0.745；在多个 LLM 上评测显示 SMART 对评测模型的选择相对不敏感。量规引导的纠错在两个数据集上均优于匹配的无量规基线，进一步带来 MER 绝对降低 0.85–0.98 个百分点、SIER_lex 绝对降低 1.18–1.65 个百分点。

批判性分析：立论与昨日的 MS-Bench 互补：一个说总分掩盖条件差异，一个说词级计数掩盖语义后果——ASR 评测确实到了该分层、分后果的阶段。方法上把"判断"拆成"分段 + 量规打标"两步，F1 比直接 LLM 判断高近 10 个点且对评测模型不敏感，说明结构化流程在压判断方差。要问的：后果标签的粒度与量规本身由作者定义，“语义后果"在不同下游（字幕、医疗记录、语音助手）权重不同，一套量规的普适性待验证；人工标签是多数票，标注者间分歧大的片段恰恰是最有信息量的部分，被多数票抹平了；纠错收益（MER 降不到 1 个百分点）诚实但不大，主要价值仍在评测侧。对做 ASR 质量评估的人，SIER 值得纳入内部评测集，但引用时注意它是"按本文量规"的语义错误率。

摘要译文：词错误率（WER）对词级编辑赋予相同代价，尽管它们的语义后果不同；而整体语义分数无法识别哪些单个错误改变了预期含义。我们将 ASR 语义评测形式化为上下文感知的、片段级的后果评估，并提出 SMART（带上下文量规的识别转录语义片段映射与评估），一个用于可追溯的语义评测和定向 ASR 纠正的框架。SMART 将参考与假设之间的差异映射为连贯片段，并应用结构化的上下文量规赋予显式的后果标签。这些标签支撑语义影响错误率（SIER），在话语、块和词级量化有后果的错误。相对多数票人工标签，SMART 取得 0.843 的 F1，而直接 LLM 判断为 0.745。在多个 LLM 上的评测进一步表明，SMART 对评测模型的选择相对不敏感，而 MER 与 SIER 揭示了 ASR 质量的不同方面。另一套无目标参考的量规使用目标假设和周围的 ASR 假设来指导纠正，在两个数据集上都优于匹配的无量规基线，并进一步带来 MER 绝对降低 0.85–0.98 个百分点、SIER_lex 绝对降低 1.18–1.65 个百分点。

6. PhonoBridge：无声语音先解码到音素，再让 LLM 按前端的错法补全文本

2610.27678

一句话：肌电（EMG）无声语音解码缺配对数据——PhonoBridge 用通道感知的 EMG→音素前端加 LLM 后端，前端噪声画像被用来扰动由 LibriSpeech 转录造出的音素-文本对（EPGA），在开放词汇无声语音数据集上 WER 24.77%，优于此前最好成绩 28.27%。

贡献/机制：两阶段框架：前端做通道级特征提取、跨通道融合与电极嵌入，输出音素；以音素为中间表征，后端训练数据可由 LibriSpeech 转录转成音素-文本对来扩充，无需额外 EMG 录音。关键设计 EPGA（错误画像引导的增强）：按前端预测估计出的错误模式去扰动转录派生的音素序列，生成额外训练对，让 LLM 提前适应前端的噪声形态。作者：Wen Qiu、Jiacheng Zhang、Xuanda Chen、Siqi Cai、Haizhou Li（李海洲组）。

数值结果：在开放词汇无声语音（Open Vocabulary silent-speech）数据集上，PhonoBridge 取得 24.77% WER，优于同一测试划分上此前报告的最好成绩 28.27%（绝对降低 3.5 个百分点）。

批判性分析：“中间表征选音素"是对的——它把稀缺的配对数据问题（EMG-文本）拆成"EMG-音素小数据 + 音素-文本大数据”，而 EPGA 是这套拆法能成立的关键：不做噪声适配，LLM 后端会被前端的系统性错误带偏，这与语音识别里"按识别器错法造训练数据"是同一思路。需要打折的：24.77% WER 离可用仍远，这是无声语音领域的常态而非本文的锅；结果只在一个数据集、一个测试划分上报告，EMG 的跨被试泛化（电极位置、个体肌肉差异）是这类方法的老大难，摘要未提被试划分方式；与 28.27% 的对比是"此前报告的最好”，是否为同协议复现未说明。对做无声语音与可穿戴语音接口的人，EPGA 的造数据方式可直接借鉴；对产品落地，WER 与跨被试问题都还没到。

摘要译文：肌电图（EMG）为将无声构音的语音解码为文本提供了一种非侵入手段，但由于配对 EMG-文本数据有限，准确解码仍然困难。我们提出 PhonoBridge，一个两阶段框架，包括一个通道感知的 EMG 到音素前端和一个用于文本重建的大语言模型（LLM）后端。前端在配对 EMG-文本数据上训练，包括通道级特征提取、跨通道融合和电极嵌入。以音素为中间表征，我们通过将 LibriSpeech 转录转换为音素-文本对来扩充后端的训练数据，无需额外的 EMG 录音。为使 LLM 适应前端噪声，我们引入错误画像引导的增强（EPGA），它按照从前端预测估计出的错误模式扰动转录派生的音素序列，为 LLM 生成额外的训练对。在开放词汇无声语音数据集上，PhonoBridge 取得 24.77% 的 WER，优于同一测试划分上此前报告的最好成绩 28.27%。

简报

1. 警用音频关键词估计：ASR 错得再系统，也能用少量人工标注把置信区间救回有效

2610.26614

用 Prediction Powered Inference 与设计型监督学习框架，把现成 ASR 输出与少量人工标注结合，估计关键词频率并给出统计有效的置信区间。在巴尔的摩与芝加哥的警用无线电音频上（现成 ASR 对业务术语有系统性错误），可做有效区间分析的领域关键词比例从"只用 ASR"的 43.0%、“只用少量人工转录"的 27.2% 提高到 56.2%，芝加哥数据上也有类似改进。对所有"拿 ASR 转录做大规模社会科学/业务分析"的人是方法论提醒：转录错误不必修到完美，后验校正可以把下游推断的有效性先保住；但 56.2% 也意味着近半关键词仍不可靠分析，结论强度要按关键词逐个看。

2. AfriBED：低资源非洲语言的 ASR 偏见评测集——班巴语与尼扬贾语

2610.26821

为两种低资源非洲语言构建按说话人子群可比对的偏见评测数据：班巴语（Bemba）9 小时、3,928 条话语、80 名说话人；尼扬贾语（Nyanja）约 18 小时、6,260 条话语、127 名说话人，用于检测与估计 ASR 在性别与说话人类型上的偏见。基线实验证明数据可用于考察这两类属性偏见。价值在"可比对的子群设计"本身——没有平行录音就测不出偏见；局限是论文主体是数据集与基线，摘要未给出任何具体系统的偏见幅度数字，想看"哪个模型偏多少"要查正文。

3. oollim：专家级 L2 英语语音评测跑在游戏 PC 上，不微调、不校准私有数据

2610.26406

本地可执行系统：组合 XLS-R、XEUS 与 PhoneticXeus 的预训练表征加参考文本特征，用在 SpeechOcean762、韩国学习者语料与 J-AESOP 上训练的岭回归，评准确度、流利度与韵律三项。在 305 条由三位专家评分的独立留出录音上，多个岭回归配置在三项构念上、Spearman 相关与二次加权 kappa 均大幅优于 2026 年 1 月取得的 Azure API 存档分数。卖点是"消费级硬件 + 预训练表征 + 按构念分开的回归"这套轻量配方；需要留意基线是存档的 API 分数而非同期同协议复跑，且"大幅优于"的具体数值摘要未给。

4. AudiPsy：抑郁评估别只做分类——让全模态 LLM 按"观察-评估-总结"逐轮攒证据

2610.27567

面向口语心理咨询对话的抑郁评估：AudiPsy 用观察-评估-总结（OAS）范式逐轮整合对话转录、文本与声学情感、以及文本-声学情感不一致，维护一份演进中的对话总结供后续轮次使用；配套构建合成口语咨询语料 AudiPsy-Counsel 并设计三阶段课程。在 DAIC-WOZ 上优于专用抑郁检测方法与通用语音/全模态 LLM，并在 EATD-Corpus 上做了自然对话的补充评测。方向（可解释的证据链而非黑盒分类）对医疗相关语音应用是对的，但摘要没有给任何数值，且训练语料是合成咨询对话——合成数据与真实咨询的分布差、以及抑郁评估本身的临床有效性，都不能凭这篇摘要下结论，只作简报跟踪。
