SeededGrasp: Language-Guided Grasping in Complex Scenes with Multiple Embodiments

将高层语义判断与低层几何抓取解耦：VLM 先给出种子点，轻量抓取生成模型再完成具体动作。

  • 作者: Yang Xu, Gurpreet Singh Mukker, Raymond Wang, Jasper Gerigk, Maria Attarian, Igor Gilitschenski
  • 来源: HuggingFace Papers（3 upvotes）
  • 链接: arXiv | PDF | 项目页/代码与数据
  • 关键贡献: 提出数据高效的 SeededGrasp 框架，由 VLM 根据语言任务预测一个三维种子点，再将其作为条件输入轻量抓取生成模型。语义推理与几何执行解耦后，无需联合端到端训练即可扩展到多种机器人形态；作者还发布了首个多形态桌面抓取数据集，包含杂乱场景中的 250 万余个抓取样本。
  • 实验结果: 相比现有基线取得更高成功率，仿真抓取成功率为 72%，真实世界实验为 78%。
  • 精评: 这个接口设计很实用：让大模型做擅长的语义定位，让小模型做精确几何控制，既减少训练成本，也降低 VLM 空间感知不足带来的风险。实际落地仍需关注种子点误差向下游传播的敏感性，以及跨相机标定、遮挡和新末端执行器上的泛化。
  • 相关技术: language-guided grasping, VLM seed-point prediction, conditional grasp generation, semantic-geometric decoupling, multi-embodiment robotics
  • 代码/权重: 数据与代码已开源 ✅
📄 Abstract 中文翻译

复杂场景中的实用机器人抓取既需要三维空间推理，也需要与具体任务要求对齐。Vision-Language Model（视觉语言模型，VLM）提供了一种通过自然语言指定这些要求的方式，但现有方法要么直接用 VLM 预测抓取动作，空间感知能力有限；要么将 VLM 与抓取模型联合训练，需要显著更多的数据和计算资源。这些局限阻碍了性能提升，也使方法难以扩展到复杂场景中的多种机器人形态。为此，我们提出 SeededGrasp，一种新颖的数据高效框架：让 VLM 预测一个种子点，并将其作为后续轻量抓取生成模型的条件。该架构将高层语义推理与低层几何执行解耦，在绕过昂贵端到端训练需求的同时支持多种机器人形态。为训练此类模型，我们发布了首个多形态桌面抓取数据集，其中包含杂乱场景中的 250 万余个抓取样本。实验结果表明，我们的方法优于现有基线，在仿真中达到 72% 的抓取成功率，在真实世界抓取实验中达到 78%。数据和代码见项目网站：https://uoft-isl.github.io/seeded-grasp/ 。

SciExplore: Evaluating Autonomous Agents from Scientific Navigation to Information Integration

面向真实科研工作流的 Agent 基准，从数据库导航逐级推进到跨来源结构化知识综合。

  • 作者: Yinhao Tang, Youqing Fang, Yanan Sun, Wenran Liu, Weiming Zhang, Bin Liu, Kuikun Liu, Wenwei Zhang, Kai Chen
  • 来源: HuggingFace Papers（0 upvotes）
  • 链接: arXiv | PDF
  • 关键贡献: 提出 SciExplore，以 103 个专家策划任务覆盖十余个学科和四类科研信息工作流：科学数据库导航、模糊文献检索、缺失引用补全、跨来源结构化知识综合。任务从实体级推理、文档识别逐步提升到证据落地与领域综合，比静态科研问答更接近实际研究流程。
  • 实验结果: 对十余种先进 LLM 和自主 Agent 的评测显示，性能会随任务复杂度增加而急剧下降，其中最困难的结构化综合任务准确率极低。
  • 精评: 这类基准对深度研究系统很有价值，因为它不把“找到一篇相关论文”误当成科研能力，而是继续追问引用是否完整、证据能否跨来源对齐、最终结构化结论是否可靠。摘要没有披露具体模型分数、成本和数据污染控制，使用时还需结合正文判断基准区分度。
  • 相关技术: scientific database navigation, ambiguous literature retrieval, missing-reference completion, cross-source knowledge synthesis, evidence grounding
  • 代码/权重: 未提及
📄 Abstract 中文翻译

科学研究涉及跨异构来源的复杂信息检索与推理工作流。然而，现有基准主要强调通用领域检索或静态科学问答，因此无法评估真实科研流程所需的关键能力。我们提出 SciExplore，一个用于评估 LLM 和 Agent 的科学信息检索与推理能力的基准。SciExplore 包含四类任务，覆盖十余个科学学科中的 103 个专家策划任务：科学数据库导航、模糊文献检索、缺失引用补全，以及跨来源结构化知识综合。这些任务从实体级推理和文档级识别，逐步考查更高层次的证据级落地与领域级综合能力。我们在 SciExplore 上评估了十余种最先进的 LLM 和自主 Agent，结果揭示出显著的性能差距：随着任务复杂度增加，性能急剧下降，在最具挑战性的结构化综合任务上准确率极低。这些结果凸显了当前模型和 Agent 在真实科学信息检索场景中的重大局限。

FilmWorld: Agentic Novel-to-Film Generation through Dynamic Cinematic World Modeling

用动态电影世界模型把小说中的抽象叙述落成可持续演化的实体状态，再通过多 Agent 协作生成长篇多场景影片。

  • 作者: Jialong Zuo, Haotong Zuo, Shiwei Zhang, Xiang Wang, Chen Li, Nong Sang, Changxin Gao, Xiang Bai
  • 来源: HuggingFace Papers（2 upvotes）
  • 链接: arXiv | PDF
  • 关键贡献: 将小说到电影生成形式化为动态电影世界建模，并拆成“构建”和“演化”两阶段。构建侧 Agent 完成叙事结构化翻译、带视觉锚定的实体状态建模和镜头规划；演化侧 Agent 负责状态锚定生成、跨镜头状态传播和闭环验证，以维持长篇内容的因果与视觉一致性。
  • 实验结果: 配套 FilmEval 用 15 部代表性小说、9 项客观指标评估电影表现、影片一致性和原著忠实度；FilmWorld 持续优于现有视频生成 Agent 系统，尤其改善叙事忠实度与跨场景一致性。
  • 精评: 真正的贡献不只是串联视频模型，而是明确维护“世界状态”，让角色、物件和情节变化成为可检查的中间表示。15 部小说的规模仍偏小，自动指标能否可靠衡量审美、节奏和改编合理性，也需要更多人工评估验证。
  • 相关技术: dynamic cinematic world modeling, multi-agent video generation, state-driven shot planning, cross-shot state propagation, closed-loop visual verification
  • 代码/权重: 未提及
📄 Abstract 中文翻译

将小说转化为电影是生成式人工智能面临的一项重大挑战，因为它要求把抽象的文学散文转换成长篇、多场景的视觉叙事。当前视频生成模型虽然擅长在狭窄时空语境中生成短小的单场景片段，但小说到电影生成处于更复杂的设定中：它要求跨越多种场景生成长时内容，同时维护动态演化的实体状态。为解决这一问题，我们将小说到电影生成形式化为动态电影世界建模，并将其分解为两个阶段：第一是构建，将抽象且描述不充分的文学叙事落地为具体、有状态且持久的世界实体；第二是演化，规定这些实体如何随情节推进而动态更新，以维持跨场景的因果一致性。我们提出 FilmWorld，一个端到端 Agent 系统，由两组专门化 Agent 协作实现这两个阶段。构建侧 Agent 执行叙事结构化翻译、带视觉锚定的世界实体状态建模，以及状态驱动的镜头规划，逐步将文学语言投射为电影蓝图。演化侧 Agent 执行状态锚定的视觉生成、跨镜头动态状态传播和闭环状态验证，以保持因果一致性和视觉连贯性。为弥补长篇生成的评估缺口，我们提出 FilmEval，一个系统性评估框架：它把由 15 部代表性小说组成、按难度分级的基准，与覆盖三个维度的 9 项客观指标自动评估协议相结合；这三个维度分别是电影化呈现、影片一致性和原著忠实度。实验表明，FilmWorld 持续优于最先进的视频生成 Agent 系统，在叙事忠实度和跨场景一致性方面的提升尤其明显。

Two-Level Meta-Rubrics for Evaluating Open-Ended Generation: GAMUT, a Benchmark for Factual Completeness

用两级元量表评估长回答是否“该说的都说了”，补上事实性评测长期偏重正确率、忽略完整性的缺口。

  • 作者: Xilun Chen, Zhaleh Feizollahi, Ross Goodwin, Seungwhan Moon, Scott Yih, Pinar Donmez, Babak Damavandi, Luna Dong
  • 来源: HuggingFace Papers（8 upvotes）
  • 链接: arXiv | PDF
  • 关键贡献: 提出两级元量表框架：上层结构化元量表表达必需内容的组织方式和重要性，再机械编译成可由 LLM Judge 稳定评分的二元检查清单。实例化的 GAMUT 基准包含 1,813 个基于真实可穿戴设备图像的问题，覆盖 10 个领域，每题均配有专家核验、证据支持的量表，并提供纯文本版本。
  • 实验结果: 在 14 个前沿及开放权重模型中，最佳的 Gemini 3.1 Pro 也仅得 58.7%；基准具有较强区分度，并且对 Judge 的选择较稳健。
  • 精评: 从“逐条查错”转向“枚举应该覆盖的内容”是关键变化，特别适合深度研究报告、医疗记录总结和多模态事件回顾。两级表示也兼顾了人类可读结构与机器可评分性；风险在于元量表本身的遗漏会形成评测盲区，而不同领域的“完整答案”边界可能存在争议。
  • 相关技术: factual completeness, two-level meta-rubrics, machine-gradable binary checklists, LLM-as-a-Judge, wearable-image grounding
  • 代码/权重: 数据集含多模态与纯文本版本；代码/权重未提及
📄 Abstract 中文翻译

长篇生成的事实性评估过去主要聚焦精确率，即衡量模型提出的主张是否正确。主流的“分解—搜索—验证”流程很擅长捕捉错误主张，却很少说明回答是否包含它应该包含的全部信息。衡量事实完整性——事实性的另一半——更加困难：它要求枚举一个完整答案应包含的全部事实，而这些事实很少构成简单的扁平列表。它们经常涉及以覆盖范围为重点的开放集合、有序过程，以及事实之间的关系；独立布尔检查项组成的列表无法捕捉这些结构。我们提出一个用于评估开放式生成的两级元量表框架，并将其实例化为 Gamut（Grounded Assessment of Multimodal Factuality，基于证据的多模态事实性评估），一个面向长篇生成事实完整性的基准。该框架建立在两级量表表示之上：结构化元量表捕捉必需内容的组织方式和重要性，然后通过机械方式编译成扁平的二元、机器可评分检查清单，由 LLM Judge 可靠打分。我们构建了 1,813 个基于真实可穿戴设备图像的问题，覆盖 10 个不同领域；每个问题均配有由专家人工标注者核验、以证据为支撑的量表。由于该框架与模态无关，我们还发布了纯文本版本。对 14 个前沿模型和开放权重模型的评估表明，该基准确实具有挑战性——最佳结果为 Gemini 3.1 Pro 的 58.7%——同时具有很强的区分度，并且对 Judge 的选择较为稳健。

FinanceComplexQA: Benchmarking Agentic Reasoning on Industrial-grade Financial Documents

面向工业级金融文档的开放式 Agent 基准，重点覆盖复杂版式、深度研究、数值计算和多跳推理。

  • 作者: Xianfu Cheng, Shiwei Zhang, Jiyu Zhao, Jian Yang, Xinyuan Wang, Ming Zhou, Weixiao Zhou, Xiangyuan Guan, Xiang Li, Zhenhe Wu
  • 来源: HuggingFace Papers（5 upvotes）
  • 链接: arXiv | PDF
  • 关键贡献: 设计 Finance-LaTeX SKILL，以专家知识合成复杂版式金融文档，并通过 Agent 工作流生成 2,000 份专业文档和 6,000 组高质量问答。进一步提出 FinanceComplexQA，包含面向 1,009 份金融文档的 2,026 个深度研究任务，支持双语并覆盖六类主流场景和七类任务。
  • 实验结果: 作者综合评测了主流 RAG 系统和 Agent 推理工具，并通过失败案例分析其在数值计算、多跳推理、内容总结和行业分析上的能力边界；摘要未披露具体排行榜分数。
  • 精评: 复杂版式和数值关系是金融文档 Agent 真正容易失败的地方，这个基准比纯文本切块问答更贴近生产环境。合成文档能稳定构造难例和永久参考答案，但也可能与真实公司的写作噪声、扫描质量和非标准披露存在分布差异。
  • 相关技术: financial document synthesis, complex-layout reasoning, deep-research QA, agent-as-a-judge, numerical multi-hop reasoning
  • 代码/权重: 未提及
📄 Abstract 中文翻译

Agentic Reasoning（智能体式推理）能够整合大规模信息并生成可靠、准确的内容，因而已经成为金融分析中的变革性力量。然而，在处理复杂真实问题时，不同 Agent 的表现仍存在显著差异。在本工作中，我们设计了 Finance-LaTeX SKILL，这是一项基于专家知识合成复杂版式金融文档的技能。利用建立在该技能之上的 Agent 工作流，我们生成了 2,000 份专业金融文档以及 6,000 组高质量问答。为评估 Agent 的综合能力，我们提出 FinanceComplexQA，一个面向金融文档、贴近真实场景的综合性开放式生成基准。它包含针对 1,009 份金融文档的 2,026 个深度研究任务。FinanceComplexQA 具有 8 项关键特征，包括：支持双语；覆盖六种主流场景和七类任务；专家级文档推理问题；针对复杂版式的深度研究；相对稳定且持久的参考答案；以及通过 Agent-as-a-Judge（智能体作为评审）和多项评估指标进行精确评估。利用 FinanceComplexQA，我们对领先的 RAG 系统和 Agent 推理工具在金融文档问答上的表现进行了综合评测。通过识别并分析失败案例，我们深入研究了它们在数值计算、多跳推理、内容总结和行业分析方面的能力。
