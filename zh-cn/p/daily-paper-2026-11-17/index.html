1. 几万小时键鼠轨迹训出的通用游戏智能体：Gamer 长程实时任务做到熟手水平

2611.18397

一句话：Gamer 把感知、记忆管理与多步推理做进一个端到端框架，先在几万小时的设备级键鼠交互轨迹上继续预训练，再用稀疏思考微调与多轮 RL 练长程交互，在多个高难度 3D 开放世界游戏里做到与熟练玩家相当的操作效率。

贡献/机制：训练分三段：先在数万小时键鼠轨迹上继续预训练，轨迹横跨模拟游戏与具身环境，让模型同时学物理与虚拟世界的环境动态；再用稀疏思考指令微调，大幅削减冗余计算、保留复杂决策所需的推理；最后用稳定的多轮强化学习训练长程交互策略，针对有限上下文窗口、累积 rollout 误差与稀疏奖励做了处理。部署侧用云边推理引擎同时服务多个模拟游戏环境，支持无界上下文执行、保持在线推理低延迟。作者：Run Luo、Kuan Zhang、Qi Deng、Yukun Chen、Zhihao Yang、Yufei Zhang、Renrong Hu、Yi Zhang、Guiyu Ma、Tianyu Fan（10 人）。

数值结果：摘要只给定性结论：多个高难度 3D 开放世界游戏上泛化与操作效率与熟练玩家相当，常规 2D 游戏基准上也有竞争力；未给出具体基准名与分数。

批判性分析：这篇的卖点是“重复的键鼠轨迹也能靠规模化出能力”——把通用智能体从文本/网页工具扩展到实时 3D 世界，且训练与部署管线同时覆盖 2D 界面与 3D 仿真，工程完整度高。但证据偏软：没有一个具体数字，所谓“与熟练玩家相当”无法核验；几万小时轨迹的数据来源与清洗方式也没展开，复现门槛不明。真正的检验要看正文的基准表与延迟数据。

摘要译文：我们介绍 Gamer，一个为复杂交互环境中的长程任务构建的通用智能体框架。其端到端架构结合感知、记忆管理与多步推理。共享的训练与部署管线支持与常规 2D 图形界面及复杂 3D 模拟世界的交互。我们首先在由数万小时设备级键盘鼠标交互构建的数据集上继续预训练，这些轨迹横跨模拟游戏与具身环境，让模型学习物理与虚拟两个领域的环境动态。稀疏思考指令微调大幅减少冗余计算，同时保留复杂决策所需的推理。我们用稳定的多轮强化学习方法训练长程交互策略，处理有限上下文窗口、累积 rollout 误差与稀疏奖励。针对实时交互，云边推理引擎可同时服务多个模拟游戏环境，支持无界上下文执行并保持在线推理低延迟。在多个高难度 3D 开放世界游戏中，Gamer 展现出扎实的泛化能力与可与熟练玩家比拟的操作效率，在一系列常规 2D 游戏基准上也取得有竞争力的结果。这些结果表明，即便是重复的键盘鼠标轨迹，也能通过数据与学习算法的规模化带来可观提升。在这类轨迹上训练有助于 Gamer 在兼具物理与数字属性的环境中更稳定地学习复杂技能。这为能跨数字与物理世界交互的通用智能体提供了一条路径。

2. 具身智能体需要自己的“系统二”：Agentic Robotics 定位论文划出定义、评测与路线图

2611.18359

一句话：GPT-6 Astra 发布后，前沿模型加具身 harness 在数周内就在许多具身基准上追平甚至超过专用策略，这篇定位论文把这种新范式命名为 agentic robotics，并给出定义、评测框架与通向持续自主的研究路线图。

贡献/机制：核心论点是“具身系统二”（Embodied System 2）——基础模型加具身 harness 构成具身机器人的决策核心，在闭环中观察环境、理解用户意图、推理任务、调用技能与工具、验证结果并调整策略。其中心挑战是把通用推理翻译成物理约束下的有效且可验证的动作：有限反应时间、机械极限、不可预测的环境变化与不可逆后果。论文提出同时度量模型能力与闭环系统表现的评测框架，梳理了从数字智能体迁移到物理智能体的原则与必须解决的挑战，并以此为基础描绘通向持续自主的路线图：从执行单个原语到承担常设角色，责任逐步扩大。作者：Grid Robotics、Qingfeng Lan、Duo Li、Siyao Li、Yiheng Lyu、Shijian Lu、Zhenghao Qi、Shizun Wang、Xinchao Wang、Ming Yang（10 人）。

数值结果：定位论文，无实验数字；摘要称前沿模型加 harness“在许多具身基准上达到或超过专用策略”，未列基准与分数。

批判性分析：这篇的价值在“定名与定框架”：当一个领域突然从“每个任务训一个策略”转向“一个基础模型加 harness 通吃”时，先把定义、评测口径与路线图说清楚，能省掉大量各说各话的争论。Embodied System 2 这个提法也抓住了关键——瓶颈不在模型会不会推理，而在推理能不能在物理约束下落地且可验证。但定位论文的通病也在：所有判断都是定性的，“追平专用策略”没有数字支撑；路线图的颗粒度要等后续工作填充。对读者来说，这篇更适合当作领域地图，而非证据。

摘要译文：GPT-6 Astra 的发布标志着机器人新范式的出现：具身智能体（agentic robotics）。在数周内，带具身 harness 的前沿模型就在许多具身基准上达到甚至超过了专用策略。与其为每类任务训练专用策略不同，具身智能体系统把基础模型用于开放世界的具身任务，在闭环中运行：观察环境、理解用户意图、推理任务、调用技能与工具、验证结果并调整策略。尽管进展迅速，社区尚未就统一定义、可靠的评测框架或研究路线图达成共识。我们认为，由基础模型与具身 harness 实现的“具身系统二”是具身智能体的决策核心，其中心挑战是在有限反应时间、机械极限、不可预测的环境变化与不可逆后果等物理约束下，把通用推理翻译成有效且可验证的动作。基于这一视角，我们提出一个同时度量模型能力与闭环系统表现的评测框架，并指出从数字智能体迁移到物理智能体的原则与必须解决的挑战。在具身系统二与评测框架之上，我们描绘了通向持续自主的研究路线图：安全可靠地执行工作、承担逐步扩大的责任，从执行单个原语到履行常设角色。

3. 只在仿真里练，27B 开源推理模型上了真机器人：LIBERO 从 1.6% 到 74.4%

2611.18562

一句话：开源 27B 推理模型此前在机器人操作上远不如 GPT-6 Astra 这类闭源前沿模型，这篇只用仿真内的机器人强化学习（RURL）、零演示，就让它在真实双臂机器人上 60% 成功，且新任务泛化远超演示微调的 VLA。

贡献/机制：像训练计算机操作智能体一样训练机器人操作智能体（RUA）：模型观察环境、用思维链推理、直接生成下一个末端执行器位姿，全程无 harness。作者搭建了机器人后训练引擎 PEAR，在仿真中大规模做机器人强化学习，先在 LIBERO 与 RoboDojo 上训练。关键是迁移：仿真中学到的技能泛化到未见过的机器人、真实世界与新指令。作者：Jiaming Tang、Zhuoyang Zhang、Junxian Guo、Fangzhou Zhao、Yilong Zhao、Zekai Li、Xingyang Li、Yuyang Zhao、Song Bian、Zhijian Liu、Song Han（11 人）。

数值结果：真实双臂机器人试验成功率 60%，基座模型为 0%；LIBERO 成功率从 1.6% 升至 74.4%，接近最大推理努力下的 GPT-6 Astra 与 GPT-6.1 Sol；在新任务的熟悉场景（LIBERO-Pro）上，演示微调的 π0.5 仅 0.75% 成功，而该模型达 57.4%；在 9 项推理、编程与视觉基准上通用能力无可测下降。

批判性分析：这是近期机器人学习里最硬的一组数字：60% 真机成功率且基座为 0，说明能力确实来自 RURL 而非基座本身；LIBERO-Pro 上 57.4% 对 0.75% 的对比，更是把“RL 泛化 vs 演示模仿”的分歧量化了。对做具身的研究者，这意味着仿真 RL 可能是开源追赶闭源的一条可复制路径。但要留神样本量：真机试验的次数摘要没给，60% 的置信区间未知；且 LIBERO 与 RoboDojo 仍是结构化仿真任务，离非结构化真实场景还有距离。

摘要译文：机器人操作智能体（RUA）已成为通用机器人控制的一条有前景的路径，但强性能迄今只属于 GPT-6 Astra 与 Claude Fable 5.2 这类前沿专有模型，开源模型的能力仍明显落后。我们证明，一个开源 27B 推理模型可以通过强化学习、完全在仿真中且无需演示，学会原生使用真实机器人。与计算机操作智能体一样，模型观察环境、用思维链推理并生成下一个末端执行器位姿，无需任何 harness。我们搭建了机器人后训练引擎 PEAR，用它在仿真机器人任务上大规模训练模型，进行机器人操作强化学习（RURL），复现前沿模型获得计算机操作能力的方式。我们发现，仿真中学到的技能能很好地泛化到训练任务之外：迁移到未见过的机器人、真实世界与新指令。在仿真中于 LIBERO 与 RoboDojo 上训练后，模型在真实双臂机器人试验中 60% 成功，而基座模型一次都未成功。在 LIBERO 上，训练把成功率从 1.6% 提升到 74.4%，接近最大推理努力下的 GPT-6 Astra 与 GPT-6.1 Sol。与经演示微调的视觉-语言-动作模型 π0.5 相比，我们的模型对任务本身的变化稳健得多：在 LIBERO-Pro 上，面对熟悉场景中的新任务时 π0.5 仅 0.75% 成功，而我们的模型达 57.4%。最后，模型保留了通用能力，在 9 项推理、编程与视觉基准上无可测下降。这些结果表明，机器人操作强化学习是基础模型后训练中一个有前景的组成部分。

4. 文本转音频也需要会讲道理的裁判：CoTTAGE 先说理再打分，六个基准人类相关性 SOTA

2611.17644

一句话：文本转音频（TTA）生成越跑越快，但现有自动评测要么与人类判断相关性差、要么给不出有依据的解释，CoTTAGE 用“先说理再打分”的推理式评估器，在文本相关性与音频质量两个维度上同时做到与人类判断最相关、解释最受人类青睐。

贡献/机制：遵循先推理后预测的范式：CoTTAGE 先生成有音频依据的诊断性理由、再预测分数，覆盖文本相关性（REL）与音频质量（OVL）两个维度。训练分两步：先用新收集的 1 万多条人类 OVL 标注做监督微调，再用强化学习精炼，奖励基于 Thurstone 偏好目标——把采样得到的分数分布转成成对偏好概率，奖励与人类判断导出排序的一致性。作者：Yu-Xiang Lin、Yun-Man Hsu、Bo-Ru Lu、Kuan-Po Huang、Wenze Ren、Ming-To Chuang、Chun-Yi Kuan、Jiawei Du、Byeonggeun Kim、Qingming Tang、Chieh-Chi Kao、Ankur Gandhe、Chao Wang、Hung-yi Lee（14 人）。

数值结果：在横跨 REL 与 OVL 的六个基准上取得与人类判断相关性的 SOTA，同时给出人类更偏好的解释；摘要未给出具体相关系数数值。

摘要译文：用工具查询数据库的前沿 LLM 智能体是目前最准确的文本转 SQL 系统之一，但每次查询都调用托管模型既慢又贵，还会把敏感的组织查询暴露给外部 API。例如，一个 Claude Opus 5.5 智能体每天服务 1 万次查询，按标价每年成本超过 7 万美元。组织已有的本地硬件能在多大程度上分担这一负担而不损害智能体准确率？我们提出 LuthorSQL，一个非自回归 7B 文本转 SQL 模型，作为慢速 LLM 智能体的快速“系统一”关口，只在不确定时才升级查询。LuthorSQL 单次前向预测有界文法下查询计划的槽位分数，编译并运行至多 32 个候选计划，再用训练好的验证器选择答案。单独使用时，LuthorSQL 在 BIRD 隐藏测试集上达到 68.03% 的执行准确率，单 GPU 每题 0.84 秒，8-bit 量化权重下 9 GB 显存仍保持准确率，并零样本迁移到 Snowflake、BigQuery、MySQL、PostgreSQL 与 DuckDB，与原生 SQLite 准确率的差距在 3.1 个点以内。与 Claude Opus 5.5 组合成预注册的置信度级联后，在 Opus 训练截止后发布的数据库上的 227 个问题中，LuthorSQL 在本地回答了近半问题，API 成本降低 33.3%，准确率不变。最后，污染探测表明，Opus 在不看 schema 的情况下能逐字复现 48–92% 的公开基准 gold 查询；但其工具辅助准确率在重命名 schema 上保持稳定，在截止后数据库上达到 95.6–97.4%。代码与数据：https://github.com/IAMIbrahimmemon/luthorsql

10. 视频语言模型读不懂动态，是因为监督没让它读：V-JEPA-LM 反事实监督让 4B 超过开源 8B

2611.17831

一句话：V-JEPA 这类世界模型编码器明明把速度等动态信息编进了特征，语言模型却只会按字幕检索属性、动态全浪费了，V-JEPA-LM 用反事实监督逼语言模型真正去“读”动态，4B 模型在 11 个视频基准平均分上超过最好的开源 8B。

贡献/机制：先定位问题：同一批题目上，线性探针能从冻住的 V-JEPA 特征以 87% 读出速度，而 VLM 回答接近随机；进一步发现动态存在于预测式编码器（如 V-JEPA）的跨视频共享子空间中，而非逐帧文本对齐编码器（如 SigLIP）的共享成分。解决办法是反事实监督：用像素变换把公开视频变成答案均衡的变体，答案由变换决定、只在变化处不同，逼语言模型读动态而非检索属性。单阶段训练、用 453 万公开样本、每帧 32 个视觉 token（开源视频 LLM 通常多阶段、900 万至 1.72 亿样本、每帧平均 64–256 token）。作者：Keuntae Kim、Dongjun Kim、Yong Suk Choi（3 人）。代码与模型已发布。

数值结果：1B 至 8B 的 V-JEPA-LM（Qwen3 与 Llama）在 11 个视频基准的平均分上领先各自尺寸档；4B 模型 72.1 分，对比最好开源 4B 的 61.1 分与最好开源 8B 的 64.8 分；同等预算下反事实监督平均 +4.5 分，自然基准的速度题上 +38 分。

批判性分析：这篇的诊断链条很完整——从“探针能读、模型不会读”的落差，到“动态住在共享子空间”的定位，再到“反事实监督逼它读”的解法，每一步都有对照实验支撑；“编码器决定能读什么、监督决定读什么”的结论也很有解释力。+38 分的速度题提升尤其说明监督信号找对了靶子。但要留神：11 个基准的平均分里各基准权重不明，72.1 分的领先幅度可能集中在动态类题目；且反事实变换的覆盖面（速度、方向、顺序、状态）是否穷尽真实动态，摘要没展开。

摘要译文：世界模型视频编码器如 V-JEPA 能仅从视频中学到场景如何变化（方向、速度、顺序、状态）。为回答问题，它们与在字幕与问答对上训练的语言模型相连。但每条字幕或问题只命名视频片段的少数属性，于是模型学会检索这些属性而非读片段，编码器携带的动态被浪费了：在同一批题目上，线性探针能以 87% 从冻住的 V-JEPA 特征读出速度，而 VLM 回答接近随机。我们展示了动态在冻住的编码器中的位置：对 V-JEPA 这类预测式编码器，动态存在于跨视频共享的子空间中，而对 SigLIP 这类逐帧文本对齐编码器则不是共享成分。随后我们构建反事实监督，让语言模型读它：像素变换把公开视频变成答案均衡的变体，答案由变换设定、仅在变化处不同。单阶段训练使用 453 万公开样本、每帧 32 个视觉 token，而开源视频 LLM 通常用多个阶段、900 万至 1.72 亿样本、每帧平均 64–256 个 token。所得 V-JEPA-LM 模型（1B 至 8B，Qwen3 与 Llama）在 11 个视频基准的平均分上领先每个尺寸档；我们的 4B 模型得 72.1 分，对比最好开源 4B 的 61.1 分与最好开源 8B 的 64.8 分。受控的编码器 × 监督研究表明，编码器决定什么能被读、监督决定读什么：在匹配预算下，反事实监督平均带来 4.5 分提升，在自然基准的速度题上提升 38 分。代码与模型：https://github.com/kkt94/Llama-V-JEPA-LM
