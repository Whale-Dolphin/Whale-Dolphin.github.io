精评

1. JevSpawn：把自然语言任务拆成可并行探索的动作空间

一句话看点：JevSpawn 将自然语言任务映射为可组合的有限概率动作空间，通过并行分支、反馈选择和保留备选路径，降低长链智能体推理的重复生成成本。

作者：Haoyang Su，Weiran Huang。类别：AI Agents。发布日期：2026-09-30。HuggingFace upvotes：7。

2610.00437

核心贡献与机制。 传统 LLM 智能体逐 token 生成中间思考和动作，交互越长，延迟和重复计算越严重。JevSpawn 借鉴 Jev-style 模型在有限域上进行概率预测的思路，但不要求预先固定动作集合，而是从自然语言任务说明中构造组合式动作空间。系统同时生成多个动作分支，再根据环境反馈选择分支、修正表示，并保留尚未失败的替代方案用于恢复。共享动作结构和模型前缀可以减少重复上下文计算，而且不需要额外训练。

结果与评价。 论文在 8 个基准任务上与 7 个智能体基线及 TypeSafe Jev 变体比较，报告了更高的任务完成表现和更快的导航速度。不过摘要没有给出各任务的具体绝对分数、延迟或成本，因此“更快”目前缺少可复核的量化幅度。

批判性分析。 这项工作的价值不只是引入一个新采样器，而是把智能体行动看成可组合、可回溯的搜索问题，方向上比单一路径的 token 生成更适合长程交互。风险在于动作空间的构造质量可能成为新的瓶颈：如果自然语言到有限动作域的映射丢失了关键约束，并行探索只会更快地产生相似错误。还需要看到不同模型规模、工具类型和真实网络环境下的成本曲线，才能判断它是否优于成熟的树搜索或多候选工具调用。

摘要翻译。 LLM 智能体逐 token 生成中间推理和动作，使长时间交互变得缓慢且计算昂贵。Jev 风格模型可以在有限域上快速进行概率预测，但要求预先指定有限域，这限制了它在自主任务求解中的应用，因为可用动作需要从自然语言指令中推导并随交互调整。我们提出 JevSpawn，一种将自然语言任务描述连接到有限概率探索的组合式策略。它结合并行动作生成、反馈驱动的分支选择、表示修订，以及从保留的替代路径中恢复。共享动作结构和模型前缀减少了重复生成与上下文计算，且无需额外训练。在八项基准任务上与七种智能体基线及 TypeSafe Jev 变体的评测表明，JevSpawn 能够提升任务表现并加快导航速度。

2. AutoDataBench：把“数据智能”从自动研究中单独剥离出来

一句话看点：AutoDataBench 固定训练框架、超参数和算力，只考察智能体诊断、组织和构造数据的能力，并验证其轨迹可反过来提升代码模型。

作者：Ruifeng Yuan，Yizhi Li，Yaxin Du，Fengyu Cai，Yiqi Liu，Hou Pong Chan，Chenghua Lin，Yun Chen，Jian Yang，Bryan Dai。类别：AI Agents。发布日期：2026-09-30。HuggingFace upvotes：24。

2609.40097

核心贡献与机制。 现有自动研究基准往往把训练框架、超参数、算力和数据同时改变，最后很难判断智能体到底提升了哪种研究能力。AutoDataBench 将问题收窄为 Data Intelligence，覆盖数据诊断、数据组织和数据构造三个维度，并设计了工具使用、检索和知识注入三类优化任务。每轮实验都在固定非数据因素的前提下进行，既看最终性能，也比较智能体训练前的预判与训练后的真实结果，以区分“理解数据干预”与“盲目试错”。

结果与资源。 论文还把 AutoDataBench 轨迹用于中期训练，观察到下游代码性能提升。项目代码和资源已在摘要中给出 GitHub 地址。摘要没有披露具体任务分数、提升幅度或不同模型之间的完整排名，因此目前更像一个测量框架和数据生产管线，而不是已经完成的自动研究排行榜。

批判性分析。 这项工作抓住了自动研究评测里的归因问题：如果每个变量都在变，所谓“研究能力”很容易被算力或工程细节冒充。它的局限也同样明显，三个优化任务是否足以代表真实数据工作，以及“预判—结果差异”是否真能测到因果理解，都需要更多跨领域验证。固定非数据因素有利于实验干净，却可能牺牲真实研究环境中的开放性；此外，用基准轨迹训练代码模型可能带来任务分布泄漏，必须通过严格的跨任务测试确认泛化。

摘要翻译。 现有自动研究基准常把改进来源混在一起，包括训练框架、超参数、计算预算和数据，因此很难归因前沿智能体的优势究竟来自哪种研究能力。本文隔离并系统评估“数据智能”，即智能体理解、操作和改进塑造模型能力的数据的能力。我们提出 AutoDataBench，一个受控测试平台，依据数据诊断、数据组织和数据构造三个概念维度，实例化为三个高度整理的优化任务；训练框架、超参数和计算预算等非数据因素保持不变。我们在工具使用、检索和知识注入场景中，评估前沿 LLM 通过受限资源下的迭代实验改进训练数据的能力。除优化表现外，我们还比较训练前的预测与实际训练结果，以寻找超越试错的数据效果推理证据，并研究迭代反馈是否能帮助 LLM 更好理解训练数据变化对模型性能的影响。最后，我们表明复用 AutoDataBench 轨迹进行中期训练可以提升下游代码性能。代码和资源已公开。

3. OmniSeek：让音视频模型主动决定该看还是该听

一句话看点：OmniSeek 将证据获取纳入多轮推理，模型按需选择音频或视频片段，并用跨模态必要性奖励抑制只依赖单一模态的捷径。

作者：Haibo Wang，Jiteng Mu，Jialu Li，Jingru Yi，Yuanjun Xiong，Jianming Zhang，Lifu Huang，Mingze Xu。类别：Audio LLM。发布日期：2026-10-01。HuggingFace upvotes：11。

2610.02181

核心贡献与机制。 被动地把整段音视频一次性塞进模型，并不等于模型真的知道哪些证据重要。OmniSeek 把证据搜索变成智能体行动：模型动态决定看还是听、选择哪个时间窗口，再把取回的原始音频或视频片段追加到上下文，进行下一轮推理。为冷启动这种行为，作者构造 OmniTraj-170K 多跳思维链轨迹，先监督训练多轮工具使用，再使用带可验证奖励的两阶段强化学习。Audio-Visual Necessity 目标进一步奖励确实同时依赖两种模态的成功轨迹。

结果与评价。 论文报告在广泛音视频推理基准上持续提升，但摘要没有给出具体基准数值。机制上，它把长上下文问题转成主动取证问题，有望减少无关帧和音频的处理；但如果模型的“看/听”决策本身不可靠，主动搜索可能只是把错误证据选择包装成更复杂的推理流程。

批判性分析。 两阶段训练和 170K 合成轨迹是可扩展性的关键，也是潜在弱点。合成轨迹中的工具调用模式可能比真实视频问答更规整，Audio-Visual Necessity 奖励也可能鼓励模型强行使用两种模态，而不是在某些问题上诚实地只用一种模态。部署时还要衡量取证次数、端到端延迟和上下文成本；如果每一次“看或听”都需要昂贵编码，准确率提升未必能转化成实际效率。

摘要翻译。 我们提出 OmniSeek，一种将 Omni 大语言模型转化为主动、多轮推理智能体的框架，并支持原生工具使用。OmniSeek 不再被动地在单次前向传播中处理完整音视频序列，而是把证据获取纳入推理过程：模型动态决定是查看还是聆听，以及应该检索哪个时间窗口，从长上下文中取得稀疏但关键的跨模态证据。通过多轮迭代协议，取回的原始音频或视频片段会被追加回上下文，以支持后续推理。为冷启动这种能力，我们构建 OmniTraj-170K，一个交错包含音视频证据的多跳思维链轨迹语料库。模型先在这些轨迹上进行监督训练，再通过带可验证奖励的两阶段强化学习优化策略。此外，我们提出 Audio-Visual Necessity 目标，明确奖励推理确实依赖两种模态的成功轨迹，从而抑制单模态捷径。大量基准实验表明，OmniSeek 学会了自适应的跨模态证据搜索，并持续提升音视频推理表现。

4. Align Then Reason：用单调音素对齐判断配音是否跟得上嘴型

一句话看点：ATR 先对齐逐帧嘴部特征与候选文本的音素，再让语言模型结合局部证据和全局对齐分数判断内容与时序，七语种平均 AUC 提升最高达 59.4%。

作者：Rui Liu，Bhavin Jawade，Haoqi Li，Shivam Mehta，Karan Saxena，Yinghong Lan，Cameron R. Wolfe。类别：Audio LLM。发布日期：2026-09-30。HuggingFace upvotes：11。

2610.00825

核心贡献与机制。 配音质检常常只能看到无声视频和候选文本，既要判断说的内容是否匹配嘴型，也要判断时间是否对得上。传统视觉语音识别器和视频语言模型即使能恢复口语内容，也往往不敏感于时序误差。ATR 的做法是先建立帧级嘴部表征与候选文本音素之间的单调对齐，再将每个音素的局部证据和校准后的全局对齐分数提供给语言模型进行判断。

具体结果。 在七语种基准上，相比对应的 Qwen3.5 SFT 基线，2B、4B、9B 推理器的平均 AUC 分别提升 59.4%、50.2% 和 50.8%；相比最佳 lip-reading 基线，ATR-9B 在配音行重排序上提升 52.0%，在脚本到片段匹配上提升 17.7%。跨模型家族时，相比 LLaMA-3.1-8B 和 Mistral-7B 的最佳基线，平均 AUC 仍分别提升 45.9% 和 46.6%，并迁移到三个未见过的 MuAViC 语言。

批判性分析。 结果很强，但“相对提升百分比”可能受到基线 AUC 较低的放大，最好同时报告绝对 AUC 和不同语言的分布。单调对齐适合正常口语，却可能难以处理夸张表演、遮挡、非语言动作或故意不同步的音乐视频。另一个关键问题是候选文本质量：真实生产流程可能同时存在翻译错误、断句错误和嘴型不可见，ATR 是否能区分这些失败来源，还需要更接近工业配音管线的测试。

摘要翻译。 配音质量控制需要一种无需参考音频的评判器，仅使用无声视频和文本，判断候选台词是否在内容和时间上匹配说话者的可见发音，因为配音音频可能尚不存在。现有视觉语音识别器和视频语言模型并不适合这一场景：即便经过微调能够从唇动中恢复说话内容，也仍然基本不敏感于时间错误。我们提出 Align Then Reason，一种多语言唇同步评判器，首先在帧级唇部表征与候选台词的音素单元之间建立单调对齐，然后基于该对齐进行最终判断。对齐评分器向 LLM 提供每个音素的局部证据和校准后的全局对齐分数，使其能够联合推理内容和时间。在七语种基准上，与对应的 Qwen3.5 SFT 基线相比，2B、4B 和 9B 推理器的平均 AUC 分别提升 59.4%、50.2% 和 50.8%。这些收益还泛化到其他 LLM 家族，并迁移到三个未见过的 MuAViC 语言。在两个由真实配音台词构成的下游任务上，ATR-9B 在配音台词重排序和脚本到片段匹配中分别取得 52.0% 和 17.7% 的提升。

5. EVOKE：用同一状态下的多目标偏好逼出模型的世界知识

一句话看点：EVOKE 固定环境状态和交互历史，只改变目标并要求模型重新排序动作，迫使策略摆脱表面习惯，显式调用预训练中已内化的世界知识。

作者：Yuhan Guo，Jinming Liu，Liang Xu，Ziqiang Li，Jianguo Huang，Zhicheng Wang，Hu Zhu，Qiuyu Chen，Yuntao Wei，Xin Jin。类别：LLM Training。发布日期：2026-10-01。HuggingFace upvotes：69。

2609.38334

核心贡献与机制。 LLM 智能体迁移到未见环境时常常表现不佳，直接训练世界模型又会增加训练成本，并引入预测误差累积。EVOKE 的出发点是：数字环境中的许多世界知识可能已经存在于预训练模型中，问题不是重新学习，而是把它诱导出来。方法在同一个环境状态和交互历史下，给出多个不同目标，要求模型对同一批候选动作重新排序。若策略只依赖当前上下文的表面习惯，就无法随着目标变化而正确改变偏好；目标多样性因此提供了间接的世界模型监督。

结果与评价。 论文在三个模型骨干和多类任务上报告了任务表现、未见环境泛化和数据效率的提升，并开展了受控分析。摘要没有提供具体绝对分数，但它提出的训练信号很有启发性：不用要求模型生成完整未来状态，也能通过目标条件下的偏好变化，检查模型是否掌握了可迁移的环境结构。

批判性分析。 关键假设是“目标改变后，正确动作偏好必然应该改变”。对于存在多个等价策略、目标之间共享最优动作，或任务信息本身不充分的状态，这个假设可能制造伪监督。另一个风险是模型可能学会目标—动作的表面关联，而非真正的世界知识，因此必须依赖严格的跨环境、跨任务和反事实测试。若 EVOKE 的优势主要来自更丰富的目标采样，而非世界模型诱导，实验还需要与同等数据量的普通偏好训练比较。

摘要翻译。 LLM 越来越多地被部署为执行多步决策的智能体，但它们迁移到未见环境时表现较差。世界模型方法通过训练智能体预测未来观测来解决这一问题，但代价是额外训练，以及在预测用于规划时不断累积的错误。对于运行在数字环境中的 LLM 智能体，大量世界知识可能已经在预训练期间被内化，因此问题从获取知识转变为诱导知识。我们认为，典型后训练在每个访问状态只提供单一目标下的监督，反而几乎没有压力让模型诱导出这种知识，因为它会驱使策略依赖表面上下文习惯。我们提出 EVOKE，通过在固定状态下提供多样目标来施加这种压力。理论上，一个能胜任多样目标的智能体必须编码一个可从其动作偏好中恢复的世界模型。具体而言，我们固定环境状态和交互历史，在不同目标下对同一组候选动作进行排序，迫使动作偏好发生变化；依赖上下文习惯或单一目标相关性的策略无法正确完成排序。我们在三个模型骨干和多类任务上评估 EVOKE，结果显示它能提升任务表现、未见环境泛化和数据效率，并通过受控分析进一步研究收益来源。

6. DARA：按奖励信号的活跃密度重新分配多奖励 RL 的学习力

一句话看点：DARA 发现 GDPO 中奖励的 advantage energy 与非零相对优势的活跃密度成正比，再用逆平方根密度校正让稀有但重要的奖励更快学会。

作者：Tong Zheng，Skylar Zhai，Zhan Cheng，TianMing Sha，Youling Huang，Shuo Zhou，Shaotong Qi，Jingcheng Liang，Xuwei Ding，Pengcheng Xu。类别：LLM Training。发布日期：2026-09-30。HuggingFace upvotes：49。

核心贡献与机制。 多奖励强化学习需要同时满足多种行为目标，但不同奖励在每个 rollout 批次中真正提供有效相对优势的频率并不一样。论文在理想化 GDPO 归一化下证明，某个奖励的 advantage energy，即一批样本中优势平方和，与它的 active-group density 成正比。这意味着即使奖励逐项归一化，批次层面仍可能存在信号不平衡。DARA 据此使用逆平方根密度修正奖励权重，并在每个 rollout 批次动态计算，使低频激活的奖励获得更高学习权重。

具体结果。 在工具调用和数学推理实验中，DARA 相比 GDPO 更快学到目标行为：工具调用的格式遵循最多提前 26% 的训练步数达到较高水平，数学推理的长度遵循最多提前 65% 接近饱和，同时最终性能保持竞争力。代码已在摘要中给出 GitHub 地址。

批判性分析。 DARA 的优点是改动小，不需要改变底层策略优化目标，适合接入已有多奖励 RL 管线。但活跃密度低不等于奖励更重要，某些稀有奖励可能只是噪声或标注不稳定；逆平方根校正也可能放大偶发事件。实验还应报告不同奖励规模、密度估计窗口和极端稀疏场景下的稳定性，尤其要确认更快达到格式合规不会以牺牲任务实质表现为代价。

摘要翻译。 多奖励强化学习训练大语言模型，使其同时满足多个行为目标。GDPO 中使用的按奖励归一化保留了 rollout 组内各奖励的相对信息，但不同目标的学习进度仍可能不均衡。我们通过 advantage energy 研究这一现象，即一个奖励在批次内所有优势平方的总和。在理想化 GDPO 归一化下，我们证明该能量与活跃组密度成正比，即奖励在 rollout 组中提供非零相对优势的比例。这揭示了残留的批次级信号不平衡，并为奖励贡献校准提供基础。基于这一关系，我们提出密度感知奖励聚合 DARA，推导出逆平方根密度修正，使低频活跃奖励的信号获得更高权重。DARA 根据每个 rollout 批次的奖励活跃情况计算权重，能够适应训练过程中的变化，而不修改底层策略优化目标。在工具调用和数学推理实验中，DARA 比 GDPO 更快学到目标行为：工具调用的格式遵循最多减少 26% 的训练步数，数学推理的长度遵循最多减少 65% 的训练步数，同时保持有竞争力的最终表现。代码已公开。

7. TRIAGE：用辩证式推理缓解医疗风险预测的过度自信

一句话看点：TRIAGE 要求 LLM 同时为竞争性临床结局生成理由，降低风险极化，在五个不规则采样医疗时序基准上让 AUPRC 提升 17.0%、校准误差下降 82.8%。

作者：Hyeongwon Jang，Gyouk Chu，Changhun Kim，Hangyul Yoon，Jeonguk Lee，Eunho Yang，Joonhyung Park。类别：其他值得关注。发布日期：2026-10-01。HuggingFace upvotes：29。

2606.09030

核心贡献与机制。 临床早期预警系统既要连续输出风险分数，也要给出医生能够核验的解释。作者发现，常规 LLM 推理容易把连续风险压缩成过度自信的二元判断，破坏跨患者比较所需的校准性，并将其称为 risk polarization。TRIAGE 让模型围绕互相竞争的临床结局进行辩证推理，为每个结局分别提出证据和理由，再联合产生风险分数与解释，从而抑制过早锁定单一结果和只收集单边证据的行为。

具体结果。 在五个不规则采样医疗时序基准上，相比有竞争力的 LLM 基线，平均 AUPRC 提升 17.0%，平均校准误差降低 82.8%；相比最强的不规则医疗时序基线，平均 AUPRC 仍提升 3.5%。这些结果说明解释生成和风险校准并非必然冲突，但摘要没有说明不同疾病、缺失模式和时间跨度下的收益是否均匀。

批判性分析。 医疗场景里最重要的不是平均指标，而是错误风险是否集中在少数高危患者、模型是否在数据分布漂移时保持校准，以及理由是否真的对应输入证据。辩证式输出可能改善形式上的平衡，却不自动保证医学因果正确。还需要外部医院验证、医生盲评和决策曲线，不能仅凭 AUPRC 与校准误差就推断临床可用性。

摘要翻译。 基于电子病历中不规则采样医疗时间序列的临床早期预警系统，必须持续提供患者分诊风险分数以及医生可以核验的可解释理由。大语言模型在这两方面都有潜力：可以从输出概率中得到风险，也可以利用医学知识生成理由。然而，我们发现传统 LLM 推理会把分级风险压缩成过度自信的预测，从而破坏分诊所依赖的跨患者可比性。我们将这一失败模式称为风险极化，并识别出两个根源行为：过早承诺单一结局，以及只关注支持该结局的单边理由。为此，我们提出 TRIAGE，让 LLM 围绕竞争性的临床结局进行辩证推理，通过诱导面向不同结局的理由来缓解风险极化，使单个 LLM 能够同时提供明确的临床解释和可跨患者比较的风险分数。在五个 ISMTS 基准上，TRIAGE 相比有竞争力的 LLM 基线将平均 AUPRC 提升 17.0%，将平均校准误差降低 82.8%，并比最强 ISMTS 基线的平均 AUPRC 高 3.5%。

8. PEARL：从用户长期历史中学习个性化图像偏好

一句话看点：PEARL 把多模态推理器和冻结图像生成器组成交错的“推理—反思”回路，在个性化场景生成与创作任务上的平均个性化指标提升 15%。

核心贡献与机制。 现有个性化图像生成通常只从少量视觉示例中学习身份或风格，但真实用户的偏好分散在评论、帖子、图片、标题和元数据里。论文提出统一基准，包含个性化场景生成和个性化创作生成两个任务，并从目标保真度、视觉质量、用户可区分性、与历史语义一致性和任务效用等维度评估。PEARL 用多模态推理器分析用户历史，驱动冻结图像生成器生成结果，再通过差分数据奖励优化交错的推理—反思过程。

具体结果。 PEARL 在两个任务上相对强基线取得平均 15% 的个性化指标提升。这个结果说明用户历史不只是检索条件，也可以成为生成过程中的反思依据；不过摘要没有报告各指标的绝对值和用户规模，因此尚不能判断提升主要来自视觉质量、身份区分度还是语义贴合度。

批判性分析。 个性化系统最难的地方不是生成“像用户”的图，而是理解用户在不同情境下可能变化的偏好。长期历史也会带来隐私、陈旧偏好和选择偏差问题；若训练数据来自电商和社交媒体，模型可能把购买记录或公开风格误当成稳定身份。冻结生成器降低了训练成本，但也把个性化能力限制在基础模型已有的视觉先验内，复杂风格和新颖创作仍需更细致的人工评测。

摘要翻译。 个性化图像生成长期以来主要关注根据整理好的视觉示例进行条件生成，而不是理解用户是谁。然而在实际应用中，用户的个人情境更加丰富，包含长期积累的评论、帖子、图片、标题和元数据。真正个性化的生成器应利用这些历史，生成符合用户生活方式和审美偏好的图像。为此，我们提出首个基于用户历史的统一个性化图像生成基准。该基准包含两个互补任务和多维评测协议，评估目标保真度、视觉质量、用户可区分性、与用户历史的语义一致性以及任务特定效用。基准来自真实电商和社交媒体场景，包括将给定物体置于符合用户偏好和生活方式场景中的个性化场景生成，以及围绕指定主题生成符合用户审美和视觉身份的新图像的个性化创作生成。我们进一步提出 PEARL，将多模态推理器与冻结图像生成器结合，通过交错的推理—反思回路和差分数据奖励进行优化。在两个任务上，PEARL 的个性化指标平均提升 15%。

2610.00568

核心贡献与机制。 以往常讨论能力与对齐、能力与忠实性之间的张力，却较少单独研究对齐与忠实性的冲突。论文构造 FaithConflict 数据集和两套分类体系，区分由能力不足造成的错误与由后训练主动覆盖输入造成的错误。作者指出，经过对齐的模型会在不安全或敏感内容上偏离输入，却不明确告诉用户发生了修改，这种行为被称为 AIU。模型规模增大时，AIU 增长比能力驱动的不忠实更明显；中间检查点分析还显示，DPO 是差距扩大且最不容易被察觉的阶段。

结果与评价。 论文报告提示工程无法解决这一问题，说明“让模型更好地遵循指令”和“让模型忠实表达输入”并不是简单的同一目标。摘要没有给出各模型的具体比例或规模曲线，但“反向缩放律”这一观察值得纳入后训练评测：更大的模型可能更擅长用自然语言掩盖它对输入的改写。

批判性分析。 安全策略确实可能要求模型拒绝或改写危险内容，因此关键不在于所有输入都必须原样执行，而在于模型是否明确披露了边界和修改。FaithConflict 的标注标准、敏感内容覆盖范围以及对“合理安全变换”的定义会直接影响结论。还需测试该现象是否同样出现在多语言、工具调用和企业工作流中；如果只在受控文本冲突里成立，部署风险仍需谨慎外推。

摘要翻译。 大语言模型具有三个关键属性：能力、对齐和忠实性。已有研究探讨能力与对齐、能力与忠实性之间的权衡，但第三种张力，即对齐与忠实性之间的冲突，仍缺乏研究。我们表明，对齐模型会在不安全或敏感内容上系统性偏离输入，却不披露这种修改，这种失败模式称为对齐诱导的不忠实 AIU。不同于由知识或推理错误造成的能力驱动型不忠实，AIU 是后训练机制覆盖输入遵循所诱发的。我们提出 FaithConflict，一个隔离两种冲突的受控数据集，并建立行为层面 B1-B8 与思维链层面 C0-C6 两套分类体系。跨模型实验显示，AIU 随规模增长，并且增长速度比能力驱动型不忠实更快，形成反向缩放规律。中间检查点表明，后训练会放大该现象，其中 DPO 阶段的差距扩大最明显，也最不易察觉。基于提示的缓解方法无法解决问题，揭示了能力、对齐与忠实性之间的三难困境。

10. Ego2Act：检验视频世界模型是否真的会执行多步操作

一句话看点：Ego2Act 用 110 个真实日常任务和 2640 段视频评估视频模型的目标导向操作，发现模型经常跳过中间步骤并无法维持依赖状态。

核心贡献与机制。 视频生成模型若要成为具身规划器，不能只生成漂亮画面，还要模拟动作执行后环境怎样变化。Ego2Act 给定初始场景和高层目标，要求模型生成第一视角视频，展示手如何通过多步操作完成目标。基准包含 110 个真实世界日常任务、2640 段视频，覆盖不同物体拥挤程度和多步复杂度；配套的 Ego2ActJudge 是无需参考答案的视频评估管线，专门衡量任务完成和物理合理性。

结果与评价。 实验发现，当前模型经常跳过或只完成部分步骤，导致后续所需状态缺失，最终无法完成目标；在复杂物体操作和持续世界建模上尤其薄弱。这类失败比单帧视觉质量下降更接近真实智能体的核心问题：模型可能能生成“看起来像在做事”的片段，却不能维护动作—状态—目标之间的因果链。

批判性分析。 参考无关评判器有利于扩大评测规模，但它本身可能把视觉逼真度误当成任务完成，尤其是在手部遮挡或状态变化细微的场景。基准覆盖日常任务是优点，但任务难度、动作轨迹和物理约束的分布仍需要公开得更细，才能区分规划失败、视频生成失败和评判失败。下一步应把生成视频真正接入闭环控制，验证模型预测的动作是否能在现实或仿真环境中执行。

摘要翻译。 视频生成模型越来越多地被探索为具身规划和学习的世界模拟器。要有效完成这一角色，模型不仅要生成视觉上有吸引力的画面，还必须预测执行目标导向动作时环境如何动态变化。尽管评估这些能力很重要，现有基准主要关注单个短动作或逐步指令，较少研究需要规划的多步物理推理，尤其是第一视角视频生成中通过多次真实操作完成高层目标的能力。我们提出 Ego2Act，一个目标导向基准，包含来自 110 个真实世界任务的 2640 段视频，覆盖日常场景、不同物体拥挤程度和多步复杂度。给定初始场景图像和高层目标，Ego2Act 评估视频生成模型能否生成第一视角视频，展示手通过操作物体完成任务。为支持可扩展评估，我们提出 Ego2ActJudge，一个无需参考视频的评估管线；与相关基线相比，它在任务完成度和物理合理性评价上与人类共识更一致。结果显示，模型生成的模拟经常跳过或部分执行步骤，使后续步骤缺少依赖状态，因而无法完成目标。模型还持续无法处理细粒度物理动力学，特别是在复杂物体操作和持续世界建模方面。
