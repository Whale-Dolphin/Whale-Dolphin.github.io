精评

1. Meta 发布 Muse Spark Open：816B 开放权重模型，独立评测排位不及中系开源模型

  • 发生了什么：据 AINews 与 ai0.news 汇总，Meta 发布多模态 MoE 模型 Muse Spark Open，总参数约 816B、每 token 激活约 42B，上下文 100 万 token，面向编程与长程 agent 任务。权重以定制许可证发布：年收入超过 2000 万美元的模型即服务厂商需与 Meta 另行签约。部署侧的最大卖点是本地运行——NVFP4 量化检查点约 530GB，可在两台 512GB 内存的 M5 Ultra Mac Studio 上经 MLX 运行，vLLM、llama.cpp 等均已首日支持。
  • 为什么重要：这是美国阵营迄今参数规模最大的开放权重发布，也是 Meta 与 Apple 在端侧推理上罕见的公开协作。但独立评测给出的信号更值得看：能力排位并未与参数规模成正比，开放权重的竞争重心正从「谁更大」转向激活效率、agent 实测与许可证友好度。
  • 关键细节：Artificial Analysis 给该模型智能指数 39 分，为美国开放权重模型最高，但低于 GLM-5.3（45）与 Kimi K3（44）；其单项弱点集中在 agent 类评测，九个头部开放模型中垫底。AINews 称该模型是新 MSL 组织训练的首个基座模型，闭源版 Spark 1.3 明显更强。
  • 不确定性：评测分数与成本估算来自 Artificial Analysis 等第三方口径；许可证对大型托管商的实际约束效果尚待市场验证。
  • 来源：AINews / Latent Space 报道

2. Anthropic 向 METR 开放员工级权限，外部审计首次「驻场」前沿实验室

  • 发生了什么：据 TLDR AI 与 Intelligibberish 报道，Anthropic 让 METR 的研究人员以近似员工的权限进驻公司：配发公司电脑与办公空间，可接触模型、训练信息与内部风控工具，独立评估前沿模型风险与公司安全实践，且 METR 发布结论无需 Anthropic 批准。Anthropic 仅能要求删改预定义类别的敏感内容，而 METR 可公开说明删改是否合理。结构上，METR 位于 Anthropic 三层外部审查体系的最高层。
  • 为什么重要：外部评估长期受制于「黑盒 API + 厂商筛选材料」，评估者看到的系统与公司内部理解的系统之间存在结构性信息差。把评估者变成「驻场检查员」——类比监管机构派驻大型银行的常驻审查员——是第一个试图从制度上弥合这一差距的安排，若跑通，很可能成为其他实验室被要求跟进的范式。
  • 关键细节：此举源于今年 9 月 Anthropic CEO 的公开承诺；OpenAI 已表态将采取同样做法，Google、Meta、Nvidia、xAI 则已签署白宫层面的独立审查协议。
  • 不确定性：驻场权限的实际深度、METR 首批公开结论的质量与 Anthropic 的回应方式，都要等第一批评估发布后才能判断。
  • 来源：TLDR AI 报道

3. 微软披露 MAI-Base-2 预训练全栈：2.8T 参数、80B 激活，效率主张引发口径争议

  • 发生了什么：据微软官方技术博客（经 TLDR AI 与 AINews 汇总），微软已完成基座模型 MAI-Base-2 的预训练：MoE 架构，总参数约 2.8T、激活约 80B，在 1.6 万张 GB200 上训练 38 天，使用约 40T 文本 token 加 10T 多模态 token，全程采用 Muon 优化器与自研的超参缩放律。微软称其在自建留出评测上超过所有受测开放权重模型，并估算其训练配方达到同等水平所需的 FLOPs 仅为 DeepSeek-V4-Pro-Base 的约十二分之一到四分之一。后训练正在进行，后续计划经 Foundry 向企业客户提供。
  • 为什么重要：这是微软第一次完整公开自研前沿基座的训练配方细节，标志着其模型战略从「依赖 OpenAI」转向「自有全栈 + 对外授权」。数据策略上微软强调训练语料来源可溯、不依赖对其他模型的蒸馏——在蒸馏合规争议升温的背景下，这本身就是面向企业客户的卖点。
  • 关键细节：效率对比所用的 bits-per-byte 指标在微软自有验证集上计算，多位外部研究者已指出这一口径有利于自家模型；MFU 约 21%、goodput 约 89% 为微软自报。
  • 不确定性：后训练版本尚未发布，所有对比均为预训练阶段的厂商自测口径，独立复现缺位。
  • 来源：Microsoft AI 技术博客

4. Goodfire 研究者主张「神经网络本来就是干净的」：多义性可能主要是工具假象

  • 发生了什么：据 ai0.news 与 AINews 报道，Goodfire 的 Nick Cammarata 发表长文，论证机械可解释性领域长期视为前提的「多义性 / 叠加」现象——即单个神经元同时编码多个无关概念——在很大程度上是早期分析工具太弱造成的假象：借助 agent 化的深入分析，许多著名案例可以被直接读懂，网络本身并不需要先经稀疏自编码器「拆解」才能研究。他举例称，在 Qwen-32B 中约九成神经元只承担单一职责。
  • 为什么重要：如果这一主张成立，可解释性的技术路线会被改写：过去数年大量投入的 SAE 分解层可能并非必需，直接研究原始神经元就能推进对齐所依赖的理解能力。AINews 汇总的社区反应中，有研究者称之为领域级时刻，也有知名研究者公开表示不改变其基本判断。
  • 关键细节：反对意见集中在三点：弱激活尾部是否携带记忆性事实未被处理；解释质量应以神经元模拟的 KL 等量化标准检验；正式论文尚未发表，目前只有长文与示例。
  • 不确定性：这是单一研究者的纲领性主张而非同行评审结论，关键数字来自其自有分析流程，外推到万亿参数模型尚无独立验证。
  • 来源：ai0.news 报道

简报

5. Anthropic 向投资者披露 Q3 收入 168 亿美元，环比增近五成

据 Intelligibberish 转述 FT 投资者日报道，Anthropic 第三季度收入达 168 亿美元，较二季度的约 115 亿美元增近 50%，剔除股权激励后的调整经营利润率约 11%，且已实现正自由现金流。值得注意的是口径变化：公司不再主打「年化运行收入」，同时主动压降了占收入约 5%–7% 的蒸馏业务——两点都被解读为在为提交 S-1、迎接 IPO 做数字整备。（来源：Intelligibberish 报道）

6. NVIDIA 发布 Nemotron 3.5 Super VL：120B 多模态 MoE，配套 2.8T token 印度语料

据 NVIDIA 官方博客，该模型为混合 Mamba-Transformer MoE，总参数 120B、激活 12B，上下文 100 万 token，由更大的 Nemotron 3 教师经 1T token 蒸馏后做 agent 向软件工程中训练，Artificial Analysis 智能指数约 26.5 分。同步开源的还有与 IIT Madras 合作的 2.8T token 印度语言预训练语料，覆盖 22 种语言的原生与罗马化文本；仅加入 10B 印度语 token，就使该模型在五项印度语言基准上提升约 5–10 个百分点。（来源：NVIDIA Developer Blog）

7. Vercel 网关数据：开放权重已占七成 token 量与近四分之一支出

据 Vercel 发布的 AI Gateway 生产指数（2026 年 10 月刊，数据截至 9 月），开放权重模型处理了其网关 71.5% 的 token 量、拿下约 23% 的支出，支出份额较 6 月增长逾四倍；同期网关总支出约为去年 12 月的 13 倍，而每 token 均价下降 47%。近七成花在中国模型上的钱经美国本土服务商结算，模型层与推理服务层的国别正在脱钩。（来源：Vercel AI Gateway Production Index）

8. Perplexity 开源 agent 沙箱平台 SPACE

据 Perplexity 官方博客，其 Computer agent 背后的沙箱平台 SPACE 以 Apache 2.0 开源：每个 agent 任务运行在独立的 Firecracker 微虚拟机中，凭据与网络出口由虚拟机外部管控，支持暂停、恢复与会话分支。安全测试中，具备虚拟机内 root 权限的模型在 108 次逃逸尝试中无一触达宿主机。该平台自 7 月起支撑 Perplexity 全部 Computer 会话，日均创建沙箱达数百万级。继 Modal 沙箱收入破圈之后，agent 执行环境再添一个生产级开源选项。（来源：Perplexity Hub）
