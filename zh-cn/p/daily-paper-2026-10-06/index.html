精评

1. 扩散 TTS 的 test-time 分工：refinement 补可懂度，search 补音色身份

2610.03320

一句话：masked-diffusion TTS 的 test-time compute 不是万金油——加 refinement 步数提可懂度、做 best-of-K search 提说话人身份，两者各管一摊。

贡献/机制：扩散 TTS 有两种计算：模型深度（参数）与 refinement 步数（推理预算），两者是否等价此前没人拆开测。本文训 15 个 masked-diffusion codec TTS（19–133M 参数、3 seeds），2000 小时语音；推理时 sweep refinement 步数 T∈[1,16]，在 174 个 held-out 说话人上用 ASR WER（可懂度）与说话人验证（身份）双指标测 zero-shot；再对比 best-of-K search 的效果。

数值结果：相对可测下限，refinement 补上可懂度 gap 的 86.2%、身份 gap 仅 46.4%——1.86× 不对称；3×/6× 训练延长后收窄为 1.84→1.36→1.23×，但未反转（可懂度随步数饱和、身份继续涨）；best-of-K 在 4 个独立 encoder 上以 64.6–79.0% 胜率补回 refinement 够不着的身份；可分的 B(d)B(T) 拟合显著优于替代模型（ΔAICc=+69.3）；剩余身份 deficit 的 62% 在 codec 不在 generator。

批判性分析：第一次把"test-time scaling"在语音里做了双维拆解，“62% 在 codec"是给 codec 派的明确信号；但 19–133M 小模型 + 2000h 数据的结论，搬到大模型/高保真 codec 上是否成立待验。做 diffusion TTS 推理优化的人必读。

摘要译文：语音的扩散语言模型结合了两种计算：模型深度（参数）与 refinement 步数（推理预算）。我们问它们在不同能力上是否等价扩展。我们训练 15 个 masked-diffusion codec TTS 模型（19–133M 参数、3 个 seed），2000 小时语音，推理时 sweep refinement 步数 T∈[1,16]，在 174 个 held-out 说话人上以 ASR 词错率（可懂度）与说话人验证（身份）测 zero-shot 合成。相对可测下限，refinement 补上可懂度范围的 86.2%，但身份范围仅 46.4%——1.86× 不对称，在多个误差度量下稳健。用 3× 与 6× 训练延长重训能收窄但不反转该 gap（1.84 到 1.36 到 1.23×），因为可懂度随步数饱和而身份继续改善。Best-of-K search 在 refinement 失效处补回说话人身份，在四个独立 encoder 上胜率 64.6–79.0%。深度与步数不可互换：可分的 B(d)B(T) 拟合显著优于替代模型（ΔAICc=+69.3）。分析表明剩余身份 deficit 的 62% 在 codec 而非 generator。我们得出结论：refinement 与深度针对不同瓶颈，应分别优化。

2. DuplexJev：frozen LLM 不解码，单 token 直接读出语音决策

2610.02638

一句话：全双工语音 agent 的小决策不用 autoregressive 解码——ASR encoder 隐状态过小 connector 进 frozen LLM，单 token 分布直接读答案。

贡献/机制：DuplexJev 把 ASR encoder 的 hidden states 经小 connector 喂进 frozen LLM，每个问题被读作其选项上的单 token 分布——什么都不解码；训练用 readout 答案 token 的 cross-entropy，而非常规的 transcript distillation（其 teacher 根本听不见声音），distillation 只保留给内容部分；encoder 与 LLM 可互换。

数值结果：8 卡节点上，8 条 utterance 的 80 个决策约 0.1s 答完；last-layer connector 下 spoken QA 90%，接近直接读 transcript 的 91%；cross-attention connector 下性别/情感准确率均达 90%（分别从 55%/28% 起），spoken QA 只掉 1 个点（83%→82%）。权重、训练 recipe、batch 推理管线与双语 spoken-QA 集已发布。

批判性分析：把语音 agent 的"快思考"做成了分类头——0.1s/80 决策的工程价值直接；但"决策"限于封闭选项，开放式响应仍要解码，适用边界要看清。做全双工语音 agent serving 的人必读。

摘要译文：全双工语音 agent 要做大量小的封闭决策，现有系统靠缓慢的自回归解码回答。我们提出 DuplexJev，把 ASR encoder 隐状态经小 connector 喂进 frozen LLM，把每个问题读作其选项上的单 token 分布。不做任何解码，8 卡节点约 0.1 秒回答关于 8 条 utterance 的 80 个决策。用 last-layer connector，spoken QA 接近读 transcript 的水平（90% 对 91%）。DuplexJev 还能听出说话人：cross-attention connector 下性别与情感准确率均达 90%（从 55% 与 28% 起），spoken QA 仅降 1 个点（83% 到 82%）。我们用 readout 答案 token 的 cross-entropy 训练决策，而非常规的 transcript distillation（其 teacher 从未听见声音），把 distillation 留给内容。Encoder 与 LLM 可互换；我们发布权重、训练 recipe、全双工 serving 的 batch 推理管线与双语 spoken-QA 集。

3. DriftTTS：免蒸馏的 few-step TTS，NFE=4 打平 Matcha-TTS

2610.03390

一句话：few-step TTS 不蒸馏也行——DriftTTS 用 distribution-matching drift 目标，NFE=4 的 MOS 逼近真值。

贡献/机制：few-step 神经 TTS 通常依赖缩短的 diffusion/flow-matching schedule，或从多步 teacher 蒸馏。DriftTTS 是 few-step mel 谱生成器，无 generative teacher、无蒸馏、无对抗判别；在 raw mel + frozen masked-autoencoder（同 LJSpeech split 预训练）定义的 mel 域特征空间里用 distribution-matching drift 目标训练；on-policy rollout 让 decoder 在自己的中间状态上训练，支持到训练 rollout 深度的推理。

数值结果：LJSpeech 上 NFE=4：MCD 3.87dB、WER 3.7%，对 Matcha-TTS 的 3.85dB/3.4%；全配对盲听 MOS 4.18，对 Matcha-TTS 3.96、真值 4.22。代码已发布。

批判性分析：“免蒸馏 few-step"把训练链条砍短了，MOS 接近真值很亮眼；但只在单说话人 LJSpeech 上验证，多说话人/零样本泛化没说。做高效 TTS 的人值得一看。

摘要译文：Few-step 神经 TTS 常依赖缩短的 diffusion 或 flow-matching schedule，或从预训练多步 teacher 蒸馏。为摆脱这些依赖，我们提出 DriftTTS，一个 few-step mel 谱生成器，训练不用 generative teacher、蒸馏或对抗判别。DriftTTS 在由 raw mel 与 frozen masked-autoencoder encoder（在同一 LJSpeech 训练 split 上预训练）定义的 mel 域特征空间里用 distribution-matching drift 目标。On-policy rollout 在 decoder 自己的中间状态上训练它，支持到训练 rollout 深度的推理。LJSpeech 上，NFE=4 的 DriftTTS 达到 3.87dB MCD 与 3.7% WER，对 Matcha-TTS 的 3.85dB 与 3.4%。全配对盲听测试中 DriftTTS 得 4.18 MOS，对 Matcha-TTS 3.96、真值 4.22。这些结果证明了不用预训练 generative teacher 的 few-step 合成的竞争力。代码已发布。

4. SSL 蒸馏纠错：抗噪靠的是 cross-correlation 对角线，不是 self-correlation

2610.02823

一句话：correlation 蒸馏里真正抗噪的是 cross-correlation 对角线——self-correlation 项只重组特征空间、不去噪，之前两篇论文都归功错了。

贡献/机制：correlation-based 蒸馏有两项：cross-correlation（对齐师生表征）与 self-correlation（去相关学生特征）；原方法与 De’HuBERT 都把抗噪功劳给了 self-correlation 项，却从没做隔离实验。本文在 LibriSpeech-100 蒸馏 + held-out CHiME-3 10dB 噪声上，用无偏全维 probe、Pearson 方差分解、同噪声因果对照、逐维分析定位真正的机制。

数值结果：加上 cross-correlation 项后，噪声分类准确率从 76.98% 降到 55.02%（噪声不变性增强）；把 self-correlation 项加回来是 55.55%——基本没动；self-correlation 项改善干净下游任务准确率，但几乎不去噪。9 个语音/音乐任务验证出设计规则：cross 项加权管抗噪、self 项调参管下游、师生噪声独立采样。

批判性分析：一次漂亮的"纠错式"机理解剖，设计规则可直接抄作业；但实验集中在 LibriSpeech-100 蒸馏设定，大 teacher/大数据下的推广待验。做语音 SSL 蒸馏的人必读。

摘要译文：自监督（SSL）语音模型准但大。知识蒸馏压缩它们，但学生丢掉 teacher 的噪声鲁棒性。Correlation-based 蒸馏用两项解决：cross-correlation 对齐学生与 teacher 的表征，self-correlation 去相关学生的特征。原方法与 De’HuBERT 都把功劳给了 self-correlation 项而没有隔离它。我们证明了相反的结论。在 LibriSpeech-100 蒸馏 + held-out CHiME-3 10dB 噪声上，无偏全维 probe、Pearson 方差分解、同噪声因果对照与逐维分析认定 cross-correlation 对角线是鼓励噪声不变性的机制，把噪声分类准确率从 76.98% 降到 55.02%；而把 self-correlation 项加回来是 55.55%。self-correlation 项转而重组特征空间、改善干净下游任务准确率，但几乎不去噪。在九个语音与音乐任务上，这给出蒸馏的具体设计规则：cross-correlation 项加权管噪声鲁棒性，self-correlation 项调参管下游性能，师生噪声独立采样。

5. RED：用 PMI 找出问题真正需要的模态证据，专治"加了视频反而答错”

2610.02976

一句话：AV-LLM 的跨模态幻觉，病根常是"不该看的模态插了嘴”——RED 用 PMI 找出问题真正需要的证据，训练免做。

贡献/机制：观察：单模态能答对的题，加上另一模态置信度反而掉（听到小提琴、看到吉他视频后动摇）。Relevant Evidence Decoding（RED）是 training-free 方法：用 pointwise mutual information 量化 audio/video 相对纯问题提供的预测支持，把联合贡献拆成 audio、video、残差交互三分量；先用纯问题推理判定所需证据类型，再把对应 PMI 分量叠回原 AV 预测。

数值结果：3 个 AV 幻觉基准 × 3 个 AV-LLM：CMM 最高 +7%、AVHBench +6.3%、SVHalluc +3.8%；首 token 相对延迟为标准解码的 1.5×。

批判性分析：training-free、即插即用是最大卖点，“证据按需增强"比全局 contrastive decoding 更对症；但 1.5× TTFT 对实时语音 agent 是笔开销。做多模态幻觉的人值得一看。

摘要译文：Audio-visual 大语言模型（AV-LLM）仍易受跨模态幻觉影响——一个模态错误地影响对另一模态的预测。虽然 contrastive decoding 能减少 vision-language 模型的幻觉，但直接搬到 AV-LLM 忽略了一个关键挑战：不同问题需要不同的感知证据，包括音频、视频或其交互。值得注意的是我们观察到，即使模型能从单个信息模态恢复正确答案，联合 audio-visual 推理也可能削弱预测。例如被问听到什么乐器时，模型可能仅从音频正确预测小提琴；一旦加上显示吉他的视频，它对小提琴的置信度可能下降。本文引入 Relevant Evidence Decoding（RED），一个 training-free 方法，识别问题相关的证据并选择性增强其贡献。RED 用 pointwise mutual information 量化 audio 与 video 超出纯问题的预测支持，把联合贡献拆成 audio、video 与残差交互分量。纯问题推理先判定所需证据类型，模型再把对应的 PMI 贡献叠加到原 audio-visual 预测上。在三个 audio-visual 幻觉基准与三个 AV-LLM 上，RED 相对标准解码在 CMM 上最高提升 7%、AVHBench 6.3%、SVHalluc 3.8%，首 token 平均相对时间为 1.5×。

6. 个性化 ASR：给气管造口+重度构音障碍使用者做的专属系统，CER 降一半

2610.03017

一句话：给一位气管造口+重度构音障碍的捷克语使用者做的专属 ASR——CER 相对 Whisper Base 降一半，孤立词识别超过人类助手。

贡献/机制：发布 33 小时公开数据集，用"artificial conversation"采集协议（保参与感与对话真实感）；Whisper Base 多阶段管线：标准捷克语微调 → 声学仿真气管造口语音 → 说话人自有数据；在脚本对话、问答、自发对话三种近实时场景评测。

数值结果：字符错率相对 Whisper Base 基线降 50%；孤立 utterance 的声学识别超过其助手们的平均人工听辨准确率。

批判性分析：accessibility 方向的硬核工作——公开数据集 + 真实用户反馈，比刷榜更有分量；但单说话人，个性化管线的通用化成本没讨论。做无障碍语音的人必读。

摘要译文：本工作为一位有永久气管造口、重度构音障碍（其语音对未经训练的听者不可懂）的捷克语使用者呈现个性化 ASR 系统。我们发布含该说话人 33 标注小时语音的公开数据集，用新颖的"artificial conversation"协议采集，兼顾高参与感与对话真实感。我们提出基于 Whisper Base 的多阶段训练管线：在标准捷克语上微调、声学仿真气管造口语音、再用说话人数据。我们在三种近实时场景评测：脚本对话、问答与自发对话，字符错率相对 Whisper Base 基线降 50%，并在孤立 utterance 的声学识别上超过其助手们的平均识别准确率。我们证明，即使对严重受损的语音，有用的 ASR 仍可实现，定量结果与说话人反馈均为证。数据集已公开。

7. FASTDIAR：因果帧级 encoder 做流式说话人日志，单 CPU 线程 5 倍实时

2610.02941

一句话：流式说话人日志别再拿 utterance 级 encoder 切重叠块了——FASTDIAR 把 SOTA 说话人识别架构改成因果帧级 encoder，单 CPU 线程 5 倍实时。

贡献/机制：现有系统多用 utterance 级说话人 encoder 切短重叠块——算力浪费且优化目标错位。FASTDIAR 把 SOTA 说话人识别架构改成因果帧级 encoder：读一遍流、每 80ms 从有界 2 秒窗吐一个 embedding；配在线聚类，每次更新前用流自相似度门控；只用 utterance 级 teacher 在仿真+域外混合数据上蒸馏训练，一套超参走天下。

数值结果：低重叠基准上最准的流式 diarizer、亚秒延迟；说话人增多时退化远小于 cache 式系统；单 CPU 线程 5 倍实时。

批判性分析：“为流式任务优化流式架构"说对了病根，工程指标（CPU 5× 实时）可直接落地；高重叠场景的数字没给，会议硬骨头待验。做实时对话 agent 的人必读。

摘要译文：实时对话 agent 需要流式、跑在 CPU 上的说话人日志。多数系统把 utterance 级说话人 encoder 用在短而重叠的块上，既浪费算力又优化了错误的任务。我们转而把 SOTA 说话人识别架构变成因果帧级 encoder：读一遍流，每 80ms 从有界 2 秒过去音频窗吐一个 embedding；配在线聚类，每次更新都用流的自相似度门控。只用 utterance 级 teacher 在仿真与域外混合数据上蒸馏训练、一套固定超参评测，该系统是低重叠基准上最准的流式 diarizer、亚秒延迟，随说话人增多退化远小于 cache 式系统，单 CPU 线程 5 倍实时。

8. 同传"何时落子"可以自学：prefix 监督不要 transcript，校准误差降 63–68%

2610.02612

一句话：同传模型"何时落子"可以自己学——用模型自己的全/局部波形翻译做 prefix 监督，不要 transcript 也不要人工译文。

贡献/机制：Simultaneous speech translation 要在源说完前吐出有用的目标文本，且已提交的 token 不能收回。本文改造 full-utterance speech LM：prefix 监督来自模型自身的完整与局部波形翻译；对比单轮 forced-prefix 与多轮 append-only 解码；推理时 confidence 阈值控质量-延迟 tradeoff；训练 prefix 密度另配 synthesis margin。

数值结果：FLEURS/CoVoST2 三个语向，prefix 训练全面改善质量-延迟前沿，confidence 给出最宽且持续有竞争力的操作区间；多轮训练下 commit-calibration error 整体降 63–68%、早期 prefix 降 68–80%，低延迟段多轮解码更强；单轮训练仅轻微改善；小 synthesis margin 有时把前沿推向更低延迟（尤其短句），大了反而伤质量与校准。

批判性分析：simultaneous 的"决策校准"被单独拿出来优化是亮点，63–68% 的校准误差下降很实在；三个语向的绝对延迟数字摘要没展开。做流式语音翻译的人必读。

摘要译文：同传必须在源说完前吐出有用的目标文本，同时保证每个已提交 token。我们改造 full-utterance speech language model：prefix 监督来自其自身的完整与局部波形翻译，不需要 transcript 或人工译文。我们对比单轮 forced-prefix 与多轮 append-only 解码，用 confidence 阈值控制推理时质量-延迟 tradeoff，并以独立的 synthesis margin 改变训练 prefix 密度。在 FLEURS 与 CoVoST2 的三个语向上，prefix 训练相对未改造模型改善质量-延迟前沿，confidence 给出最宽且持续有竞争力的操作区间。多轮解码在低延迟普遍更强；多轮训练下 commit-calibration error 整体降 63–68%、早期 prefix 降 68–80%，而单轮训练仅轻微改善整体校准、早期 prefix 无改善。小 synthesis margin 有时把前沿推向更低延迟（尤其短句），大 margin 则损害翻译质量与校准。Prefix 改造改善同传（尤其多轮 append-only 解码），而 synthesis 密度带来非单调的质量-延迟 tradeoff。

9. 音乐生成的后训练：ALM rubric 转 DPO 偏好对，三项指标同涨

2610.03589

一句话：音乐生成的 RLHF 别只盯一个自动指标——ALM 按 rubric 打分转 DPO 偏好对，CLAP/SongEval/Audiobox-Aesthetics 三线同涨。

贡献/机制：文本到音乐的后训练需要捕捉多维度音乐质量的 reward 信号，单一自动指标不够。本文研究结构化 rubric-based reward：预训练 ALM 按 rubric 给每个生成片段打分；同 prompt 的候选按分排序转偏好对，做 DPO（MusicGen-small、ACE-Step v1）；rubric 分数也可直接做 DiffusionNFT 的标量 reward；在 tempo/key/instrumentation（有精确客观 reward）上对比验证。

数值结果：MusicCaps 上 rubric 优化让 CLAP、SongEval、Audiobox-Aesthetics 同时涨，DiffusionNFT+ACE-Step 涨最多；反观 MusicGen-small 上任一单指标建偏好对：目标指标涨、其他独立指标掉（trade-off 实锤）；客观 reward 专练 tempo/instrumentation 可靠，ALM rubric 对 tempo/乐器只有部分迁移、key 无改善。

批判性分析：“ALM rubric 管难形式化的宽泛感知质量、客观 reward 管能量化的属性"这个分工结论干净利落，对后训练有直接指导；但只在 MusicCaps 上验证。做音乐生成后训练的人必读。

摘要译文：文本到音乐生成的后训练需要捕捉多维度音乐质量的 reward 信号，超出任一自动指标的度量。我们研究结构化 rubric-based reward：预训练 audio-language 模型（ALM）按 rubric 给每个生成片段打分；我们把同文本 prompt 的候选按分排序转成偏好对，在 MusicGen-small 与 ACE-Stepv1 上做 DPO，并把 rubric 分数直接用作 DiffusionNFT 在 ACE-Stepv1 上的标量 reward。MusicCaps 上 rubric-based 优化同时改善 CLAP、SongEval 与 Audiobox-Aesthetics，DiffusionNFT 在 ACE-Step 上增益最强。相比之下，MusicGen-small 上用任一自动 evaluator 建偏好对都产生清晰的跨指标 tradeoff：目标 evaluator 改善而其他独立 evaluator 恶化。我们进一步研究 tempo、key 与 instrumentation（有精确客观 reward）：直接优化这些专用 reward 可靠地改善目标属性，而 ALM rubric 对 tempo 与 instrumentation 只有部分迁移、对 key 无可测改善。合在一起，这些结果给出实用的分工：ALM rubric 对难形式化的宽泛感知质量有效，而有可靠度量时专用客观 reward 仍是首选。

10. 无监督 F0 跟踪：显式声门相位建模，F0 准确率超监督 tracker

2610.03058

一句话：神经 vocoder 学不会 F0，是因为谱损失给不了相位监督——显式建模声门周期的瞬时相位，F0 直接微分出来，不用外部 tracker。

贡献/机制：知识驱动的神经 vocoder 端到端学不好基频：谱目标对周期结构监督弱、缺相位信息。本文用 source-filter 模型 + 无混叠加性声源，让声门周期的瞬时相位显式可微——微分即瞬时频率即 F0，无需外部 tracker；波形误差只监督确定性谐波路径，谱损失覆盖全信号。

数值结果：M4Singer/LM-SSD 上重建相位对齐，信号-重建误差比 8.1dB（神经基线为负）；LM-SSD 上恢复的 F0 准确率超所有参评方法（含开箱即用的监督神经 pitch tracker）；声门闭合瞬间识别距 REAPER 仅 0.53 个点；但给了外部 F0 的 GOLF 谱失真仍更低。

批判性分析：无监督 F0 超监督 tracker 是硬结果，“相位显式化"的建模思路值得 vocoder 圈借鉴；但 GOLF 对比说明谱建模仍有代差。做神经 vocoder/pitch 建模的人必读。

摘要译文：知识驱动的神经 vocoder 难以端到端学出可靠的基频，因为谱目标对周期结构监督弱且缺相位信息。我们用 source-filter 模型解决：无混叠加性声源让声门周期的瞬时相位显式，微分即得瞬时频率从而得 F0，无需外部 tracker。波形误差只监督确定性谐波路径，谱损失覆盖全信号。M4Singer 与 LM-SSD 上重建相位对齐，信号-重建误差比达 8.1dB，神经基线为负。然而，给了外部 F0 的 GOLF 谱失真仍更低。LM-SSD 上恢复的 F0 达到所有参评方法的最高整体准确率，包括开箱即用的监督神经 pitch tracker；声门闭合瞬间距 REAPER 的识别率仅 0.53 个点，无需任何 F0 标注。

11. 可合并的语音-音乐 encoder：换 correlation loss，两种合并算法都受益

2610.02836

语音+音乐双域小 encoder 的合并，蒸馏 loss 本身影响可合并性：把 DistilHuBERT 的 Lkd 换成 correlation-based Lcl，权重插值下 17/18 组对比更接近各自较好的端点、语音任务在所有插值权重下领先；activation permutation 下需重排的通道更少、匹配通道相关性更强。点评：跟精评 4 同一 loss 的另一面——表征好，两种合并算法都受益；但只在固定架构/评测下验证，跨架构待验。

12. ParaGeo：在 frozen speech LM 里给副语言变异量出"共享坐标”

2610.03125

80 种请求控制 × 12 benchmark 家族 × 8 句，matched-content 分解后把 pooled K/V 投到共享低维空间；内容 held-out 下 centroid 准确率 9.49%（permutation 基线 1.25%），跨内容同标签余弦 0.285（基线 0.017），p=0.001；静态/加性/时序干预呈属性-层-调度依赖的响应。点评：给副语言结构量了把"共享坐标尺”，是 latent speech control 的经验起点；但绝对数值仍低，离可控生成还远。

13. GAANet：音画语音分离的非对称融合，3.3M 参数拿 SOTA

2610.02752

音频/视觉流各取最优时间分辨率交互，不再对称降采样；每模态压成单时间维的全局 token 做高层语义引导。LRS2 上 16.5dB SI-SNRi、VoxCeleb2 14.0dB，3.3M 参数/19.8G MACs 的轻量身板拿 SOTA。点评：“非对称+全局引导"两处改动都打在点上；但评测限 LRS2/VoxCeleb2，强噪声/多人重叠待验。

14. 音乐长上下文增益 71%，几乎全是"精确 copying”

2610.02837

符号音乐自回归模型 6→336 token 的 NLL 下降 71%，几乎全由精确 copying 解释：copy 基线恢复 94% 的增益，抹掉历史中的复现段增益即消失；在 MAESTRO/MusicNet（复现少）上增益仅 9%/18% 且 96 token 即饱和。点评：给"长上下文"泼了盆冷水——先问模型到底在利用什么；另附对一篇旧稿的方法论纠错（split leakage 等四宗罪），测上下文长度的人该读。

15. 人声合唱多音高估计：线性 STFT 打败 harmonic CQT

2610.03656

线性 STFT 打败 harmonic constant-Q transform，且特征抽取更便宜；加长分析窗/拓宽频谱覆盖无额外增益，短窗对时变人声音高更有效。点评：“更细的频率分辨率≠更好"是反直觉但扎实的结论；但结论限人声合唱场景，乐器 MPE 待验。

16. LALM+声学特征拼文本，构音障碍检测拿 SOTA

2610.03352

LALM 做构音障碍语音检测：光靠 LALM zero-shot 只有 chance 水平；微调时把低层声学特征+说话人人口学信息拼进文本一起喂，Qwen2-Audio-Instruct 拿下 SOTA，超纯 DL 基线。点评：“大模型+领域特征拼接"是最务实的适配路线；但数据集的临床异质性没深究。
