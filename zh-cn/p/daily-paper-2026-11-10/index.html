1. 统一图像生成：理解与生成共用一条序列，1536 分辨率开源第一，Turbo 单卡 H20 上 4.98 秒出一张图

2611.07392

一句话：WeLM-Image 把文本、参考图与目标隐变量排成一条交错序列，用共享注意力加独立参数的 Mixture-of-Transformers 同时做理解、文生图、指令编辑与多参考合成，1536 分辨率在三项开源榜单上排第一，蒸馏后的 Turbo 版在单张 H20 上 8 步 guidance-free 生成一张 1024×1024 图像只要 4.98 秒。

贡献/机制：统一图像基础模型要同时服务理解与生成，两条路径的优化目标容易互相干扰。WeLM-Image 用 Mixture-of-Transformers（MoT）主干：共享注意力、理解与生成各用独立参数，限制优化干扰；每条路径再配 Mixture-of-Experts 稀疏扩容，总存储参数 31.7B、每目标隐变量 token 激活约 5.4B 生成参数。数据一侧用知识驱动的视觉词表加大规模视觉聚类平衡语义覆盖与编辑任务，训练时评估指导数据迭代精炼；双语标注与经验证的编辑监督支撑渐进训练到原生 1.5K 分辨率。生成与编辑先分别用基于 rubric 与 checklist 的奖励优化，再经噪声感知的 on-policy 蒸馏合并成统一策略；MeanFlow 少步蒸馏得到 Turbo 版。作者：Canmiao Fu 等（16 人）。

数值结果：1536 分辨率模型在 PRISM-Bench、Qwen-Image-Bench 与 UnicBench 的整体比较中，在被评估的开源模型里均排第一；WeLM-Image-Turbo 在单张 NVIDIA H20 上用 8 个 guidance-free 步骤生成一张 1024×1024 图像耗时 4.98 秒。

批判性分析：这篇的工程完整度很高——统一架构、数据引擎、两阶段奖励优化再到少步蒸馏，是一条从研究到微信大规模消费级应用落地的完整链路；“理解与生成共享一条序列”这个设计也符合多模态统一模型的走向。但摘要没有给出与闭源模型（如 GPT 图像系列）的对照，只说“开源第一”；编辑质量的 rubric/checklist 奖励本身由谁打分、是否自举，也没有交代；31.7B 存储参数对“单卡部署”的实际显存占用（量化后多少）同样未说明，落地成本要打折扣看。

摘要译文：我们提出 WeLM-Image，一个统一图像基础模型，它把多模态理解融入文生图、指令引导编辑与多参考合成。模型为微信大规模消费级应用的单卡部署而设计，把文本、参考图像与目标隐变量处理为一条交错序列。Mixture-of-Transformers（MoT）主干结合共享注意力与独立的理解、生成参数，以限制优化干扰。每条路径配备 Mixture-of-Experts（MoE）模块提供稀疏容量，总存储参数 31.7B，每个目标隐变量 token 约激活 5.4B 生成参数。一个面向生成的数据引擎结合知识驱动的视觉词表与大规模视觉聚类，平衡语义覆盖与编辑任务，训练时评估指导数据的迭代精炼。双语标注与经验证的编辑监督支持渐进训练到原生 1.5K 分辨率。我们先用基于 rubric 与 checklist 的奖励分别优化生成与编辑，再通过噪声感知的 on-policy 蒸馏合并专门化策略。在报告的整体比较中，1536 分辨率模型在 PRISM-Bench、Qwen-Image-Bench 与 UnicBench 上在被评估的开源模型中排名第一。基于 MeanFlow 的少步蒸馏得到 WeLM-Image-Turbo，它在单张 NVIDIA H20 GPU 上用 8 个 guidance-free 步骤生成一张 1024×1024 图像耗时 4.98 秒。

2. 不要视觉编码器了：动作信号在浅层就见顶，无编码器 VLA 更稳

2611.06918

一句话：NEO-VLA 质疑 VLA 的默认结构——先由视觉编码器压缩感知、再开始动作推理，恰恰丢掉了操作最依赖的局部几何、边界与深度等信号；它改用轻量 patch 卷积直接 token 化图像、让视觉计算与语言在主干里共同演化，逐层探测显示动作关键信号往往在最终视觉表示之前就达到峰值。

贡献/机制：现有 VLA 默认“感知先压缩成固定视觉端点，动作推理再开始”，但操作依赖的信号（局部几何、边界、深度、细微状态变化）最容易在这种抽象中受损。这篇提出 NEO-VLA，一个结构上无编码器的视觉-语言-动作框架：图像经轻量 patch 卷积层 token 化后，与语言一起在主干中演化，流匹配动作专家可以从不同深度的、受指令调节的视觉表示中取信号。对照实验显示，原生架构一致优于基于编码器的对照组；全量微调能缩小差距但无法消除，单纯加规模也补不回来。逐层探测进一步表明，动作关键信号常常远在最终视觉表示之前就达到峰值。作者：Weichen Fan 等（17 人）。

数值结果：摘要未给出具体基准分数与提升幅度，只定性报告“在多样的操作设置与分布偏移下实现更强、更稳健的控制”；具体数值需看正文。

批判性分析：这个工作的提问方式很对——它不是在现有结构上加模块，而是问“视觉端点”这个默认假设本身对不对；“动作信号在浅层见顶”的探测结果如果成立，对 VLA 的结构设计有普遍意义。但摘要完全没有数字：没有基准名、没有成功率、没有与编码器基线的差距幅度，结论的可信度目前只能建立在方法论述上；“更强更稳健”到底强多少、代价是什么（无编码器是否意味着更长的 token 序列与更高的算力），都要等正文数据才能判断。

摘要译文：视觉-语言-动作模型通常建立在一个简单的前提上：感知先由视觉编码器压缩，动作推理随后才开始。然而操作常常恰恰依赖最容易在这种抽象中受损的视觉信号，例如局部几何、边界、深度与细微的状态变化。这引出一个根本问题：动作策略应该继承一个固定的视觉端点，还是直接访问不断演化的视觉计算？我们提出 NEO-VLA，一个结构上无编码器的视觉-语言-动作框架。图像由轻量 patch 卷积层 token 化，并与语言一起在主干中共同演化，使流匹配动作专家能从不同深度的、受指令调节的视觉表示中汲取信号。这个简单的改变揭示了一个一致的模式。在受控比较中，原生架构优于基于编码器的对照组；全量微调能缩小但无法消除差距，仅靠增加规模也无法弥补。更值得注意的是，逐层探测显示，动作关键信号常常远在最终视觉表示之前就达到峰值。在多样的操作设置与分布偏移下，NEO-VLA 因此实现了更强、更稳健的控制。这些结果共同表明，具身控制受益于对计算层级各处的视觉表示的访问，而非一个固定的编码器输出。

3. 不自回归也能做决策：183 毫秒出一个带概率的判断，准度追平 GPT-6 Sol

2611.07854

一句话：Drex 把“决策”从“生成”里拆出来：给一个状态与一组选项，直接返回选项上的概率分布，不做自回归解码；最大的 27B 模型在 Decision Index 上刷新决策模型纪录，Decision Bench 上与 d3-turbo 和 GPT-6 Sol 统计持平，典型请求只要 183 毫秒，而 GPT-6 Sol 约 2.0 秒、Claude Opus 5.5 约 3.5 秒。

贡献/机制：长思维链的自回归 LLM 在生产里答案不稳定、要解析输出、又贵又慢。决策模型换一个问题形式：输入一个状态（文档、记录或智能体上下文，可选图像）与若干问题，每个问题要求在选项中选择、做 yes/no 判断，或在有序量表上打分，输出选项上的概率分布，无需自回归解码。Drex 是四个开源决策模型组成的家族：8B（DLM）、9B（v1.5）、35B 总参数 3B 激活（v2.0）、27B（Max）。训练结合监督微调与调整反馈的强化学习（RLAF），Max 另做视觉调优；消融显示 RLAF 提升准确率、一致性损失提升对选项顺序的稳健性。代码：https://github.com/nace-ai/drex-decision-models。作者：Nischay Dhankhar、Alisher Amantay、Zhanibek Datbayev、Darkhan Akhmetov、Yash Shah、Nurmukhamed Ubaidullayev、Raman Saparkhan、Dos Baha、Abulhair Saparov（9 人）。

数值结果：Decision Index 0.4.1 上 Max 以 67.52 分刷新所比较的决策模型纪录（Jev 1.14.0 为 60.70）；Decision Bench v4 上与 d3-turbo 和 GPT-6 Sol 统计持平，比 Claude Opus 5.5 低 1.6 分；在 DecideBench 上决策模型中准确率最高；典型请求耗时 183 毫秒，对 GPT-6 Sol 约 2.0 秒、Claude Opus 5.5 约 3.5 秒；输出在选项重排下稳定。

批判性分析：这篇的定位很清晰——不是要替代通用 LLM，而是把“判断”这个高频、低容错的生产环节抽出来做成便宜又快的专用模型；183 毫秒对 2 秒的延迟差在智能体循环里是质变，而且概率输出天然适合做校准与阈值控制。但要注意适用边界：决策模型只擅长“选项给定”的判断，开放式生成、长推理仍需自回归模型；Decision Bench 上落后 Opus 5.5 的 1.6 分说明天花板仍在通用大模型手里；RLAF 的“调整反馈”具体如何构造，摘要没有展开，复现要看正文。

摘要译文：采用大语言模型的自回归方法，例如长思维链推理，已成为新 AI 应用的默认选择，因为它们在广泛任务上达到更高准确率。然而在生产中，它们给出的答案不一致、需要解析输出，并增加成本与延迟。决策模型解决这一问题：给定一个问题与用户提供的一组选项，它们返回选项上的概率分布，无需自回归解码。我们提出 Drex，一个由四个开放决策模型组成的家族，参数量分别为 8B（DLM）、9B（v1.5）、35B 总参数 3B 激活（v2.0）与 27B（Max）。每个请求由一个状态（文档、记录或智能体上下文，可选图像）与关于它的若干问题组成，每个问题要求在选项中选择、做 yes/no 判断，或在有序量表上打分。训练结合监督微调与调整反馈的强化学习（RLAF），Max 另有视觉调优。消融表明，RLAF 提升准确率，一致性损失提升对选项顺序的稳健性。在 Decision Index 0.4.1 上，Max 在我们比较的决策模型中创下新的 state of the art（公开套件 67.52 分，对 Jev 1.14.0 的 60.70 分）。在 Decision Bench v4 上，它与 d3-turbo 和 GPT-6 Sol 统计持平，比 Claude Opus 5.5 低 1.6 分，并且在 DecideBench 上是决策模型中准确率最高的。Max 回答一个典型请求耗时 183 毫秒，而 GPT-6 Sol 约 2.0 秒、Claude Opus 5.5 约 3.5 秒，且其输出在选项重排下保持稳定。四个模型全部开源：https://github.com/nace-ai/drex-decision-models

4. 物理研究的端到端大考：56 个真人课题，22 个模型没有一个通过超 46/168 次

2611.06910

一句话：FrontierPhysics 不考固定习题、而是让智能体从头做物理研究：42 位物理学家按自己的研究出题，56 个任务横跨理论、计算与实验九个领域，要求查文献、定计划、做实验、写出结构化产出与科学手稿；22 个模型、26 种配置里，没有一种配置在 168 次 rollout 中通过超过 46 次。

贡献/机制：现有物理基准只评固定问题、孤立子任务，或在给定解法下复现论文，很少同时检查研究的正确性与质量。FrontierPhysics 是端到端基准：56 个任务由 42 位物理学家基于自己的研究制作，覆盖九个领域；每个任务要求智能体查阅文献、制定研究计划、开展研究与实验，并产出结构化输出与科学手稿。评估结合确定性验证器与专家撰写的 rubric，同时判断研究是否正确、是否达到可发表水平。作者进一步人工审阅智能体轨迹，发现前沿智能体的主要短板是推理不够严谨、专家直觉有限，而非物理知识或执行错误。作者：Bingran You 等（72 人）。

8. Agent 进化不是只涨不跌：16 个进化体全都一边学会新任务一边丢掉旧任务

2611.07624

一句话：智能体 harness 进化（不更新模型权重、只进化 harness 的递归自我改进）被默认等同于“分数涨了就是变强了”，但这篇的对照实验显示：16 个进化智能体全部一边获得此前未覆盖的任务、一边丢失此前已覆盖的任务；有个通用任务案例里可靠性涨了 5.2 分，代价是丢掉 10 个此前能做的任务。

贡献/机制：智能体 harness 进化能在不更新模型权重的情况下实现递归自我改进（RSI），但更高的基准分数是否等于可靠、高效、可迁移的改进，一直没有检验。这篇评估四种方法在不同 harness、通用任务与编码任务上的表现：重复评估、受控的智能体扩展、组件干预与准入重放，揭示出反复出现的模式——16 个进化智能体全部获得此前未覆盖的任务，同时丢失此前已覆盖的任务；一个通用任务案例中，可靠性上升 5.2 分，但代价是丢失 10 个此前已覆盖的任务；多数可靠性收益同时增加部署成本；具体改动通常优于通用提醒，但组合后收益可能变化；得分最高的智能体在四个池子中的任何一个上都不是平均改进最大的；更严格的准入可能丢弃有用的替代方案。迁移上也有选择性：通用任务目标上跨两种 harness 类型与范式时覆盖率通常下降，而编码任务目标上、使用仅外层 harness 时覆盖率上升。作者据此提出“保真感知评估”、经检验的决策规则与明确的适用条件，并给出建设性后续 EvoAudit——把这些诊断转化为 select、analyze、mutate、gate 四步的修订，取得最佳表现。作者：Xiaobo Wang 等（16 人）。

数值结果：16 个进化智能体全部出现“获得新任务、丢失旧任务”；通用任务一例中可靠性 +5.2 分、丢失 10 个已覆盖任务；EvoAudit 取得最佳表现（具体数值见正文）。

批判性分析：这篇是对“进化 = 进步”这个默认叙事的必要纠偏——它把评估从单点分数拉回到“保真度”（学会新东西的同时保住旧东西）这个更诚实的维度上；“得分最高的智能体不是平均改进最大的”尤其值得所有做 RSI 的人记住。但摘要没有给出 EvoAudit 的具体数值与基线对比，建设性方案的说服力目前不足；实验只覆盖四种方法与两类任务，结论在更广的 harness 空间里是否成立仍待验证；“可靠性”的具体定义（多次运行的方差？）摘要也没有展开。

摘要译文：智能体 harness 进化使递归自我改进（RSI）无需更新模型权重即可实现。我们检验更高的基准分数是否带来可靠、高效、可迁移的改进。我们在不同 harness、通用任务与编码任务上评估四种方法。重复评估、受控的智能体扩展、组件干预与准入重放揭示出反复出现的模式。全部 16 个进化智能体都获得了此前未覆盖的任务，同时丢失了此前已覆盖的任务。在一个通用任务案例中，可靠性上升 5.2 分，尽管丢失了 10 个此前已覆盖的任务。多数可靠性收益也增加了部署成本。具体改动通常优于通用提醒，但其收益在组合后可能变化。得分最高的智能体在我们四个池子中的任何一个上都不是平均改进最大的，更严格的准入可能丢弃有用的替代方案。迁移有选择性地保留收益：在通用任务目标上，跨两种 harness 类型与范式时覆盖率通常下降，而在编码任务目标上、使用仅外层 harness 时覆盖率上升。这些发现促使我们采用保真感知评估、经检验的决策规则与明确的适用条件。作为建设性后续，EvoAudit 把这些诊断转化为 select、analyze、mutate 与 gate 的修订，取得了最佳表现。

2611.09382

一句话：权重空间编程（WSP）让推理智能体直接检查与修改神经网络参数、替代基于梯度的模型适配；这篇系统检验它的能力边界：只改 1023 个参数，MATH-500 准确率就能涨 29.45 分，GPQA Diamond、IFEval、SciBench 上分别涨 4.42、36.72、17.11 分；但 16 条编辑轨迹里有 6 条因无法可靠验证改进而保留原始权重，效果并不稳定。

贡献/机制：权重空间编程（WSP）使推理智能体能直接检查与修改神经网络参数，提供基于梯度模型适配之外的另一种选择，但其能力、跨任务泛化与实际局限一直缺乏系统理解。这篇通过 16 条编辑轨迹、在 7 个基准与两个模型规模（Qwen3.5-0.8B 与 Qwen3.5-9B）上系统研究 WSP。三点发现：第一，WSP 能通过高度定位的干预实现显著的性能提升——完整 held-out 评估上，准确率在 MATH-500、GPQA Diamond、IFEval、SciBench 上分别最多提升 29.45、4.42、36.72、17.11 个百分点，其中只修改 1023 个参数就带来 29.45 分的提升；第二，WSP 表现出有前景但不均匀的跨任务泛化——数学编辑后的检查点无需进一步编辑，就把 GPQA Diamond、IFEval、SciBench 分别提升 3.03、12.18、20.10 分，而 SciCode 性能不变；第三，有效编辑仍然困难且不一致——结果在不同轨迹间差异很大，16 条轨迹中有 6 条因候选改进无法可靠验证而保留原始权重。主页：https://wsp-scope.github.io/，代码：https://github.com/WSP-Scope/WSP-Scope-Project。作者：Junru Hu、Cheng Tang、Wei Li、Hongze Zhu、Chun-Mei Feng、Qi Zhang、Yirong Chen、Ming Hu（8 人）。

数值结果：MATH-500 +29.45、GPQA Diamond +4.42、IFEval +36.72、SciBench +17.11（百分点，完整 held-out 评估）；1023 个参数带来 29.45 分提升；数学编辑检查点跨任务迁移：GPQA +3.03、IFEval +12.18、SciBench +20.10，SciCode 不变；16 条轨迹中 6 条保留原始权重。

批判性分析：1023 个参数换 29.45 分这个数字非常抓人——它说明大模型里确实存在少量“杠杆点”参数，定位编辑的上限很高；跨任务迁移（数学编辑顺带提升 IFEval 20 分）也暗示这些杠杆点可能对应更通用的能力维度。但这篇的诚实之处也恰恰是它的短板所在：6/16 的轨迹以“无法验证改进”告终，说明 WSP 目前更像一个有潜力的研究方向而非可靠工具；编辑的发现过程（智能体如何找到这 1023 个参数）成本未量化；实验只用了 Qwen3.5 两个规模，杠杆点的存在是否依赖模型家族未知。

摘要译文：权重空间编程（WSP）使推理智能体能直接检查与修改神经网络参数，提供基于梯度的模型适配之外的另一种选择。然而，其能力、跨任务泛化与实际局限仍未得到充分理解。我们通过 16 条编辑轨迹、在 7 个基准与两个模型规模（Qwen3.5-0.8B 与 Qwen3.5-9B）上系统研究 WSP。我们的发现揭示三个关键洞见。第一，WSP 能通过高度定位的干预实现显著的性能提升。在完整 held-out 评估上，准确率在 MATH-500、GPQA Diamond、IFEval 与 SciBench 上分别提升最多 29.45、4.42、36.72 与 17.11 个百分点。值得注意的是，仅修改 1,023 个参数就带来 29.45 分的提升。第二，WSP 表现出有前景但不均匀的跨任务泛化。一个经数学编辑的检查点在无需进一步编辑的情况下，把 GPQA Diamond、IFEval 与 SciBench 分别提升 3.03、12.18 与 20.10 分，同时 SciCode 性能保持不变。第三，有效编辑仍然困难且不一致。结果在不同轨迹间差异很大，16 条轨迹中有 6 条因候选改进无法可靠验证而保留原始权重。总之，这些结果突显 WSP 在高度定位的模型适配上的潜力，同时揭示了干预发现、可靠性与跨任务迁移方面的实际挑战。主页：https://wsp-scope.github.io/ GitHub：https://github.com/WSP-Scope/WSP-Scope-Project

10. 推理过一次就别再算了：CPU 可执行的推理缓存，比源模型便宜 16–291 倍

2611.09891

一句话：CPU-ARC 指出 LLM 总在重复造轮子——把任务求解与解法的执行混在一起，每个问题都从头解一遍；它从 LLM 推理轨迹里构造 CPU 上可执行的智能体推理缓存（ARC），在困难数学与科学任务上与前沿 LLM 表现相当，调用成本却便宜 16–291 倍，还完全可解释、可持续训练、对输入扰动稳健。

贡献/机制：大语言模型把任务求解与解法的执行混为一谈，迫使每个问题都从头解决。这篇表明，一旦一个任务被推理过，把它的解法应用到新问题实例上可以非常高效、几乎不需要语言模型参与。作者提出智能体推理缓存：从 LLM 推理轨迹中构造稳健的、CPU 可执行的智能体推理缓存（ARC）。ARC 在一系列困难数学与科学任务上与前沿 LLM 表现相当，完全可解释、可持续训练、对输入扰动稳健，调用成本比源模型便宜 16–291 倍。作者：Peter Belcak、Greg Heinrich、Saurav Muralidharan、Shizhe Diao、Pavlo Molchanov（5 人）。

数值结果：困难数学与科学任务上与前沿 LLM 表现相当；调用成本比源模型便宜 16–291 倍。

批判性分析：这个思路的吸引力在于它把“推理”与“执行”拆开——昂贵的推理只做一次，之后复用的是便宜、可解释、可审计的缓存，这对需要反复解同类问题的部署场景（客服、科学计算、代码生成）很有价值；“完全可解释”在需要合规的场景里也是加分项。但摘要没有给出具体的任务名、分数与基线对照，“表现相当”到底相当到什么程度无法判断；缓存的构建成本（需要多少条推理轨迹、覆盖率如何）也没有交代；16–291 倍这个区间跨度很大，下限与上限分别对应什么场景同样未知。

摘要译文：大语言模型一直在重复造轮子。它们把任务求解与解法的执行混为一谈，迫使它们从头解决每个问题。我们表明，一旦一个任务被推理过，把它的解法应用到一个新问题实例上可以非常高效，且几乎不需要语言模型参与。我们提出智能体推理缓存，一种从 LLM 推理轨迹中构造稳健的、CPU 可执行的智能体推理缓存（ARC）的方法。ARC 在一系列困难数学与科学任务上与前沿 LLM 表现相当，完全可解释、可持续训练、对输入扰动稳健，且调用成本比源模型便宜 16–291 倍。

11. 线性注意力的门控再分配：10M token 外推不漂移，32K 下训练比 Transformer 快 2.7 倍

2611.08376

线性注意力把上下文压缩进固定大小的键值状态，实现线性时间训练与常数内存推理，但门控 delta 规则模型的擦除与写入并不对称：作者证明状态更新对擦除的敏感度远低于写入——键激活与单位归一化把键能量集中到稀疏通道子集，而值写入缩放全部通道，因此擦除门可以用更低秩参数化；慢衰减的状态行累积的范数远大于快衰减行，主导无加权读出、迫使写入时更强擦除以抑制干扰。据此提出的 Muir 把全部门融合进敏感度分配的低秩投影，用匹配滤波读出门重加权状态行，并把省下的参数投回更宽的前馈网络。166M–1.34B 参数上，Muir 比 Gated DeltaNet-2 困惑度低 1.8–2.0%、比 Transformer 低 2.5–3.6%，常识准确率最多高 1.9 分；1.34B 模型在多跳与多针召回上超过两个基线，从 4K 训练长度外推 2560 倍到 10M token 流而困惑度不漂移，静态读出下 1M token 内 passkey 检索接近 100%；达到 100B token 验证损失比 GDN-2 快 1.2 倍，32K 下训练比 Transformer 快 2.7 倍。作者：Tushaar Gangavarapu、Gil Tabak、Clemens JS Schaefer（3 人）。

12. 视觉规划不必逐 token 生成：整条轨迹一次解码，快约 25 倍

2611.08449

物理 AI 任务（机器人、自动驾驶）可以用视觉规划（点、框、轨迹）表示空间目标与预测运动，但自回归视觉语言模型逐个坐标 token 生成规划，预测越丰富代价越高。VFlash 用 Flash Primitive Decoding：利用视觉基元的已知结构、通过轻量 drafter 一次前向生成整个基元，布局随基元类型、维度与长度自适应；且空间精度不需要复现自回归模型的精确 token 序列，因此直接在标注基元上训练、接受结构有效的预测。在 2D 与 3D 机器人轨迹任务上，VFlash 持续降低预测误差；初步单 rollout 测量显示 3D 点运动预测生成快约 25 倍；以 VFlash 规划为条件的世界动作模型在四个 MolmoSpaces 任务套件上平均成功率 70.2%，对基线 62.6%。作者：Yu-Cheng Chou 等（19 人）。

13. 多智能体交接要签名：不安全提交从 69.4% 压到 9.0%，但提取那一步仍是信任边界

2611.07483

企业 AI 智能体常把用户请求拆给子智能体再合并结果，每次交接都可能概括掉、篡改或忽略一条需求。这项预注册研究比较自由文本、结构化 JSON 与带签名的需求清单三种交接方式：编排器把每条需求抽成逐字引用加可检查谓词，用 HMAC-SHA256 给清单签名，确定性代码验证合并者的决策。Qwen3-8B 上 1,440 条轨迹、五种威胁下，带签名清单把受攻击时的不安全提交从 69.4% 压到 9.0%（60.4 个百分点，95% CI [51.4, 69.4]），合规提交净损失为零；签名专门防传输中篡改——无签名清单在变异运行中有 79% 提交违规，带签名的为零；同一轨迹上确定性验证器捕获 78.7% 的违规决策，对 LLM 检查器的 59.0%，误报 7% 对 50%。但预注册的签名前注入攻击确认了边界：一条对抗性文本让带签名清单的违规率从 14.6% 升到 37.5%（Qwen3-8B）、11.1% 升到 63.9%（gpt-oss-20b）、8.3% 升到 75.0%（GPT-5.6-luna）——签名保护的是传输中的需求，不是提取时的需求，提取步骤才是信任边界。作者：Xiaobo Chen、Genliang Zhu、Ziyuan Wang、Chu Wang（4 人）。

14. 别只调模型和 harness：优化环境本身，Haiku 4.5 成本降 72.7%、通过率涨 14.34%

2611.07372

智能体的成本与成功率取决于模型、harness 与环境，但研究只盯着前两者调参。这篇提出第三个方向：优化静态环境——多任务共享的丰富环境，如公司的 Slack 工作区或文档、票据集合。EnvOpt 用真实或合成任务、无需评分器或参考答案，对任意模型与 harness 做静态环境的自动化端到端优化。AutomationBench 上，EnvOpt 把 Claude Haiku 4.5 的成本降低 72.7%、通过率提高 14.34%；同一环境迁移到 Opus 5 上，成本降低 68.1%、提升 1.34%；叠加在 Meta-Harness 已优化的 harness 之上，又降成本 83.4%、准确率再加 11.17%；五个基准上均显著降成本且保持或提升通过率，并可迁移到不同模型与 harness。作者：Mingxuan Li、Huanzhi Mao、Qiuyang Mang、Hanchen Li、Joseph E. Gonzalez、Alex Dimakis（6 人）。

15. Nemotron 3.5 Super 从 120B 压到 74B：单张 B200 跑 128K 上下文，保留 95% 分数

2611.08290

LLM 剪枝要保质量、同时满足延迟、吞吐与显存这些硬件与负载约束，但参数量本身预测不了这些指标。AutoCompress 把硬件约束直接放进可微架构搜索，联合优化全局与逐层结构、产出异构架构，以服务引擎成本模型指导搜索（经端到端延迟、吞吐与显存实测验证）。相比 SOTA 的 Minitron 剪枝框架，AutoCompress 在 RTX 5070、RTX 5080 与 H100 上八个基准平均准确率分别高 6.57、2.35 与 0.57 个百分点；并把 Nemotron 3.5 Super 从 120B 压缩到 74B 参数，在单张 B200 上以 BF16 跑 128K 上下文，保留 95% 的平均基准分数。作者：Sheldon Liang、Ali Taghibakhshi、Saurav Muralidharan、Sharath Turuvekere Sreenivas、Ashwath Aithal、Pavlo Molchanov、Nima Tajbakhsh（7 人）。

16. 模型自称不知道的事，其实知道六成：回测防泄漏不能信自报与 cutoff

2611.06808

LLM 金融回测只有在模型不知道待预测结果时才有意义，但业界靠厂商宣称的知识 cutoff、问模型自己知不知道、或指令模型按过去日期回答来防泄漏。FinDendro 基准用 2,226 条 1999–2026 年的美国 dated 事实（月度宏观序列、月末股价、美联储决议），每条事实生成四种提示，控制后随机准确率约 0.27。结果显示多数前沿模型的自报低估了知识：GPT-5 答对 76% 的受控事实、却只声称知道 38%，且在其声称不知道的事实里答对 61%；知识宣称可延续到实测知识边界之后长达七个季度，而声明日期能消除大部分事前知识宣称、却不改变准确率。因此模型训练窗口内的回测无法靠自报、指令或宣称的 cutoff 认证为无泄漏。作者：Lingfei Qian 等（15 人）。
