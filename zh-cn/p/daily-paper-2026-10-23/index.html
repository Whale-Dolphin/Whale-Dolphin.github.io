精评

1. Qwen-Audio-3.1-ASR：ASR 旗舰往"带说话人的结构化转录 + 通用音频理解"扩了一圈

2610.28711

一句话：Qwen-Audio-3.0-ASR 的迭代版：保留 30 种语言、16 种中文方言与指令控制（历史上下文条件、分层热词定制、原生转录润色），新增说话人日志式转录（说话人标签 + 时间戳 + 文本、跨轮次标签一致、重叠语音可表示），并把通用音频理解（音频/语音/音乐描述、时间定位、声音事件检测、音频问答与选择推理）纳入同一模型家族，按异步文件转录、低延迟流式、交互语音输入、非流式识别四种部署形态出变体。

贡献/机制：这是一份技术报告，核心增量在任务形态而非新架构披露：说话人分离从"后处理步骤"变成模型原生输出的结构化字段，重叠语音在一份转录里直接表示；指令控制三件套（历史上下文、分层热词、转录润色）延续 3.0 的可控转录路线；音频理解任务面从"认词"扩到"解释说话人、声学事件及其时间关系"。作者：Chuanmeng Bian、Daren Chen、Peixin Chen 等（Qwen 团队，共 63 人）。

数值结果：摘要未给出任何基准数值：没有常规 ASR、多语言/方言、说话人日志转录与音频理解各项的 WER 或准确率，也没有各变体的延迟数据。全部效果表述停留在"评测覆盖了……展示了能力"的定性层面，具体数字需查正文表格。

批判性分析：产品形态上的信号是清楚的：头部 ASR 模型的竞争点正在从 WER 转向"转录即结构化记录"——谁说了什么、何时说的、重叠段怎么记，再叠上事件检测与时间定位，一份输出同时喂会议纪要、客服质检与多模态检索。分层热词与历史上下文条件也是真实部署里最被要的两类控制。但作为技术报告，摘要零数字使得它暂时只能当"发布公告"读：3.1 相对 3.0 在哪些语言/方言上实际进步、日志转录的 diarization 错误率、流式变体的延迟-精度取舍，都要等正文（及后续第三方复现）才能判断。对做语音产品的人，先记形态变化，引用效果时等正文数值落地再说。

摘要译文：我们提出 Qwen-Audio-3.1-ASR，一个音频语言模型家族，它在前代 Qwen-Audio-3.0-ASR 的基础上改进了语音识别，并扩展了说话人日志式转录与通用音频理解能力。该家族保留对 30 种语言和 16 种中文方言的支持，以及包括历史上下文条件、分层热词定制和原生转录润色在内的指令控制能力。说话人日志式 ASR 产生包含说话人标签、时间戳和识别文本的结构化输出，在各轮次间保持一致的说话人标签，并能表示重叠语音。通用音频理解能力涵盖音频、语音和音乐描述，时间定位与声音事件检测，以及音频问答和多项选择推理。这些任务将应用范围从识别所说词语扩展到解释说话人、声学事件及其时间关系。为适应不同的部署要求，该家族包含面向异步文件转录、低延迟流式传输、交互式语音输入和非流式识别的变体，其中某些变体提供说话人日志式转录和通用音频理解。评测涵盖常规 ASR、多语言和方言语音、说话人日志式转录以及通用音频理解，展示了 Qwen-Audio-3.1-ASR 家族在转录和更广泛的音频分析任务上的能力。

2. Heard But Not Said：LALM 不是没有时间信息，是提示问不出来

2610.29256

一句话：冻结的大音频语言模型定位不了音乐中被描述的时刻，到底是时间信息根本不在表征里，还是提取方式不对——用同一音频片段上的成对查询（状态查询 vs 变化查询）加三种提取方式（整轨提示、窗口化是否打分、注意力）对照后结论是：提示与注意力几乎暴露不出这些信息，但窗口化验证能测出来，提示的失败系统性低估了模型"能验证"的能力（尽管不低估其"能定位"的能力）。

贡献/机制：探针由 Slakh2100 的分轨激活构造：给同一时间跨度同时挂一个状态查询（如"只有钢琴和贝斯在演奏"）和一个变化查询（如"吉他退出，只剩钢琴和贝斯"），并改变模型能看到的前置音频长度。三种提取方式分别对应三个不同问题：整轨提示问"能不能说出何时"、窗口化是否打分问"把片段递到手边时能不能验证、以及需不需要前文"、注意力问"能不能自己找到该时刻"。作者：Eunsik Shin。

数值结果：摘要以定性对照为主，未给具体分数：状态查询在无上下文时即高于基线；变化查询在多数短片段模型上随前置上下文增加而改善；30 秒填充（padded）编码器没有出现可比的恢复。提示与注意力"几乎没有"暴露上述信息。

批判性分析：这篇与前两天的跨模态神经元、Text Dominance 是同一条线：LALM 的瓶颈越来越多地被定位在"表征里有、生成/回答时取不出"。它把结论收窄得很诚实——提示低估的是"验证"而非"定位"，也就是说换成窗口化打分的评测协议能测出更多能力，但产品里用户问"这段在第几秒"时模型仍然答不出，能力在不等于可用。方法上的保留：结论建立在 Slakh2100 合成分轨这一可控但人工的设定上，真实音乐（混音、无干净分轨、描述更模糊）里窗口化验证的优势还在不在未知；且"短片段模型 vs 30s 填充编码器"的对照暗示编码器的时间处理方式才是关键变量，正文需看模型清单。对做音频理解评测的人：先把自己基准的提问方式当作一个变量审一遍，再下"模型不行"的结论。

摘要译文：大音频语言模型（LALM）能理解音乐，却难以定位被描述的时刻在何时。我们追问：这反映的是时间信息缺失，还是时间跨度的提取方式存在瓶颈。我们使用一个由 Slakh2100 分轨激活构造的成对查询探针：给同一跨度同时附加一个状态查询（例如"只有钢琴和贝斯在演奏"）和一个变化查询（例如"吉他退出，留下钢琴和贝斯"），并改变向模型展示的前置音频量。在冻结的 LALM 上，三种提取该跨度的方式问的是不同的问题：整轨提示问模型能否说出何时；窗口化的是/否打分问模型在被递给该片段时能否验证该时刻、以及它是否需要之前的内容；注意力问模型能否自行找到该时刻。状态查询在没有上下文时得分即高于基线，而变化查询在大多数短片段模型中随着前置上下文增加而改善；30 秒填充的编码器没有显示出可比的恢复。提示和注意力几乎没有暴露出这些信息。因此，提示的失败低估了 LALM 能够验证的东西——但并不低估它们能够定位的东西——低估的程度由查询类型和编码器决定。

3. Omnilingual-MsASR：长音频多说话人 ASR 的能力上限测试，全模态模型的 tcpWER 经常超过 100%

2610.29455

一句话：面向全模态 LLM 的长格式多说话人 ASR 基准：6 种语言、最长 30 分钟录音、最多 20 名说话人，同时给音频与视频输入以测跨模态一致性与互补线索利用——主流全模态 LLM 评测下来瓶颈显著，tcpWER 频繁超过 100%，细粒度时间定位、说话人消歧与跨模态协同是三大短板。

贡献/机制：Omnilingual-MsASR 把"谁在何时说什么"做成可量化的基准任务：平行音视频输入让评测能区分"模型是真用了视觉线索（如口型、画面中的说话人）还是只靠音频硬猜"，并检验音视频两路给出一致答案的程度。评测对象为一批主流全模态 LLM。代码与数据：https://github.com/QwenLM/Omnilingua-Bench/tree/main/Omnilingua-MSpeaker 。作者：Yuan Ge、Pei Zhang、Xize Cheng、Lingzhou Mu、Mingyang Wang、Jin Xu、Baosong Yang、Shengxiang Gao、Jingbo Zhu、Zhengtao Yu、Tong Xiao。

数值结果：摘要给出的唯一量化锚点是：领先全模态 LLM 的 tcpWER（时间约束的说话人级 WER 口径）频繁超过 100%——即错误数超过参考词数，说明在长格式、多说话人条件下输出经常整体失控（错人、错位、幻觉式续写）。逐模型分数摘要未给。

批判性分析：tcpWER 超过 100% 这个数字本身就是结论：短音频基准上看起来"ASR 已解决"的全模态模型，一到 30 分钟、20 个说话人的真实会议形态就崩了——这与昨天 Qwen-Audio-3.1 主打的"说话人日志式转录"正好形成供需对照，专用 ASR 模型与通用全模态模型在这条线上的差距会被这类基准持续放大。需要留意的口径问题：tcpWER 对时间定位与说话人归属同时扣分，与普通 WER 不可直接横比，引用时要带口径；基准出自 QwenLM 组织仓库、评测对象又包括自家路线之外的模型，数据构造与评分实现建议等第三方复跑后再当定论。对做长音频与会议理解的人，这是目前指向最明确的一块短板标尺。

摘要译文：全模态大语言模型（LLM）在音频和视频理解方面取得了显著进展。然而，现有模型在处理长格式、多说话人视频时仍然吃力，尤其是在理解整个视频以及识别谁在何时说了什么方面。为了刻画当前全模态 LLM 的能力上限并指导未来的模型开发，我们提出 Omnilingual-MsASR：一个面向长格式多说话人自动语音识别（MsASR）的多语言、多模态基准，涵盖六种语言、最长 30 分钟的录音，以及最多有 20 名说话人的场景。Omnilingual-MsASR 提供平行的音频和视频输入，以评估模型的跨模态一致性以及它们利用跨模态互补线索的能力。对领先的全模态 LLM 的广泛评测揭示了显著的性能瓶颈，它们的 tcpWER 频繁超过 100%。这些发现凸显了细粒度时间定位、说话人消歧和跨模态协同是未来全模态基础模型的关键挑战。我们的工作见：https://github.com/QwenLM/Omnilingua-Bench/tree/main/Omnilingua-MSpeaker 。

4. RubatoCodec：给变帧率语音编解码装上"整句事件预算"，序列长度终于可控

2610.29434

一句话：变帧率编解码按内容分配 token，代价是同一设置下不同句子的 token 数飘忽不定、生成器要产多长没谱——RubatoCodec 在 X-Codec-2 基础上给出整句级精确事件预算与流式解码：用编解码特征与波形频谱的变化切分变长事件（无学习的边界预测器）、每事件用离散码 + 显式时长表示，低事件率下重建保真度与可懂度优于定帧率，配套 TTS 对比里 WER 更低、UTMOS 更高。

贡献/机制：Adaptive Firing 机制按信号变化把语音切成变时长事件，事件数由整句预算精确约束，于是"生成器预测一个事件、解码一个事件"的流式范式成立，且生成时不需要额外的帧率约束——生成器能从训练中学会遵守编解码的事件预算。在大规模多语言语音上训练的模型在英语、日语、普通话上重建质量有竞争力，在可比码率下所评英语与日语基准上可懂度保持最佳。代码与权重：https://github.com/third-intelligence/RubatoCodec 与 https://huggingface.co/third-intelligence/RubatoCodec 。作者：Chihiro Arata、Shohei Taniguchi、Gouki Minegishi、Kan Hatakeyama-Sato。

数值结果：摘要以相对结论为主、未给绝对数值表：自适应分配在低事件率下重建保真度与可懂度优于定帧率编码；同条件 TTS 对比中自适应表示取得更低的 WER 与更高的 UTMOS、UTMOSv2，说话人相似度相当；多语言重建"有竞争力"，英语/日语可懂度在所比编解码中最佳。具体码率点与分差需查正文。

批判性分析：变帧率是语音 token 化的正确方向（静音与稳态段不该和爆破音段花一样多的 token），但"长度不可控"一直是它进生成流水线的实际障碍——预算约束把这个障碍变成了接口：上层生成器按预算规划、下层编解码按预算切分，这对流式 TTS 的延迟与显存规划都是实打实的好处。不用学习型边界预测器也降低了切分模块自身成为误差源的风险。要打折的：全部关键结论（优于定帧率、可懂度最佳、TTS 收益）都没有在摘要给出数值与码率点，“低事件率"具体低到什么程度决定了结论的含金量；事件切分依赖特征/频谱变化启发式，对噪声、混响、多说话人重叠段的切分稳定性未在摘要提及。对做语音编解码与流式生成的人，这是今天最可直接上手复现的一篇（代码权重齐全），复现时先盯低码率点的绝对数。

摘要译文：神经语音编解码为语音生成提供离散 token。较低的帧率缩短 token 序列，但每个 token 随后必须携带更多的语言和声学信息。变帧率编解码通过根据语音内容调整 token 分配来解决这一权衡，但基于阈值的分配让内容决定 token 数量，因此在固定设置下，语音生成器必须产生的序列长度在不同话语和数据集之间会变化。我们提出 RubatoCodec，一种基于 X-Codec-2 构建的变帧率语音编解码，具有精确的话语级事件预算和流式解码。它的自适应触发（Adaptive Firing）机制利用编解码特征和波形频谱的变化将语音划分为变时长事件，无需学习的边界预测器。离散码和显式的时长表示每个事件，使语音生成器能够逐个事件地预测和解码。受控实验表明，在低事件率下，自适应分配在重建保真度和可懂度方面优于定帧率编码。一个在大规模多语言语音上训练的模型在英语、日语和普通话上取得了有竞争力的重建质量，并在可比码率下、在所评估的英语和日语基准上取得了所比较编解码中最佳的可懂度保持。在匹配的文本转语音对比中，自适应表示产生了更低的 WER 以及更高的 UTMOS 和 UTMOSv2，同时说话人相似度相当。语音生成器还学会了编解码的话语级事件预算，无需在生成时施加显式的帧率约束。这些结果表明，有预算的自适应语音表示同时支持高质量重建和流式文本转语音生成。代码和权重见 https://github.com/third-intelligence/RubatoCodec 和 https://huggingface.co/third-intelligence/RubatoCodec 。

5. Decodability Is Not Controllability：探针能解码说话人，不等于顺着探针方向就能换嗓音

2610.29345

一句话：连续潜空间 TTS 里，“说话人信息可被线性探针高精度解码"被默认等同于"沿该方向编辑就能控制说话人”——在 VoxCPM2 上 30 名说话人、60 个有向说话人对的位置匹配探针与等范数干预把这两件事彻底分开：最终层参考音频状态的探针准确率 0.970，沿对齐方向编辑却 0/60 达到目标主导；改在早期参考位置编辑则 60/60 命中，目标相似度 +0.326。

贡献/机制：干预实验设计是全文的骨架：同一组说话人对，在不同层、不同参考位置做等范数（equal-norm）编辑，并与任意等范数方向/位置对照比较，分离"方向对不对"与"位置对不对"两个变量；再用独立说话人编码器、留出说话人原型检索与双盲听评三路验证"听到的确实是目标说话人”。跨架构部分在 dots.tts 上复现了区分：骨干编辑只能把源说话人推开、无目标吸引；x-vector 消融把源相似度从 0.849 打到 0.006。由此提炼免训练说话人控制的两条要求：几何特异性，以及一条能把目标说话人条件真正送进声学合成的计算通路。作者：Yuanzhong Zheng、Wei Huang、Ming Ma、Kailun Jin、Youhai Jiang。

数值结果：VoxCPM2 最终残差声学语言模型层（RALM L7）的参考音频状态保留 0.970 的探针准确率，但对齐编辑产生 0/60 个目标主导的说话人对；在 L0 做成对对齐更新则目标相似度提高 0.326、60/60 全部目标主导，而任何等范数方向或位置对照至多 1/60。dots.tts 上 x-vector 消融使源相似度从 0.849 降至 0.006。

批判性分析：这是今天方法论上最干净的一篇：它证伪的是整个可解释性/控制领域最常见的推理捷径——“探针读得出 → 方向推得动”。0.970 对 0/60 的对照足够醒目，且等范数对照排除了"只是扰动幅度问题"的解释，早期位置全命中又给出了正面处方（控制点要选在条件注入的通路上，而非信息最显眼的层）。与第 2 篇 Heard But Not Said 恰好互文：一篇说表征里有但提示取不出，一篇说探针读得出但编辑推不动——“可测"与"可控"之间的缝隙正在成为音频模型分析的主战场。局限：免训练控制的结论建立在两个连续潜空间系统上，离散 token 型 TTS 是否有同样的层/位置结构未覆盖；60 个说话人对的规模对"全命中"这类强结论还偏小。对做 TTS 说话人控制与模型可解释性的人，这篇的两条要求（几何特异性 + 计算通路）可以直接当设计检查表用。

摘要译文：在连续潜空间的文本转语音（TTS）中，高线性可解码性并不蕴含因果可控性。在 VoxCPM2 中，跨 30 名说话人和 60 个有向说话人对的位置匹配探针与等范数干预揭示了这种分离：最终残差声学语言模型层（RALM L7）处的参考音频状态保留了 0.970 的探针准确率，然而对齐编辑产生了 0/60 个目标主导的说话人对。在早期参考音频位置的编辑产生相反的模式。在 L0 处，成对对齐的更新将目标相似度提高了 0.326，并在全部 60 个说话人对中实现目标主导，而在任何等范数方向或位置对照下至多为 1/60。独立的说话人编码器、针对留出说话人原型的检索以及双盲听评证实，被移动后的嗓音确实被听成预期的目标。在 dots.tts 中的跨架构干预区分了骨干杠杆作用与直接声学控制：骨干编辑使源说话人移位但没有目标吸引，而 x-vector 消融将源相似度从 0.849 降低到 0.006。这些发现确定了免训练说话人控制的两个要求：几何特异性，以及一条将预期的说话人条件带入声学合成的计算通路。

6. 跨语言克隆别把口音一起克隆：双参考闭环引导把法语口音残留压掉 73%

2610.29351

一句话：零样本跨语言语音克隆会把参考说话人的口音带进目标语言——这篇用"原始参考 + 语音转换构造的母语锚点"双参考闭环引导：两份参考初始化各自的语言模型状态、共同引导一条共享声学轨迹，每生成一个片段就同步更新两个状态；冻结的 TTS、无需逐句做语音转换，在 20 名留出法语说话人上把残留法语语种判别质量压低 73%，相似度只损失 0.042。

贡献/机制：关键设计有二：母语锚点每个说话人只构造一次、可复用，在线合成不再需要逐句 VC 级联；双状态闭环让两份参考的生成历史始终与已发出的语音对齐，避免开环引导在长句中漂移。固定设置 λ*=0.33 跨说话人通用，同一设置无重调地迁到西班牙语、残留压低 56%。作者：Yuanzhong Zheng、Wei Huang、Ming Ma、Kailun Jin、Youhai Jiang（与第 5 篇同一团队）。

数值结果：在 20 名留出的法语说话人上，固定设置 λ*=0.33 相对直接克隆将残留法语 LID（语种判别）质量降低 73%，ECAPA 相似度代价仅 0.042，且相对仅用锚点的克隆恢复了 0.155；在留出测试各臂中取得最低的平均 WER（0.009）和最高的平均 GOP（4.750）。盲听偏好中，母语为英语的听众在发音自然度上更偏好它胜过直接克隆，在说话人身份上更偏好它胜过仅锚点克隆与 TTS→VC 级联。在线 RTF 约比级联低 26%（0.59 对 0.80）；同一设置将西班牙语 LID 质量降低 56%，无需重新调参。

批判性分析：问题定位准：跨语言克隆的"口音泄漏"与"音色保持"是一对矛盾，单参考只能二选一，双参考把"像这个人"与"像母语者"拆成两个可分别加权的条件源，再用闭环解决长句漂移——工程上比"TTO→VC 级联"少一次完整合成、RTF 还低 26%，是能进流水线的设计。需要打折的：评测规模是 20 名法语说话人 + 一个西班牙语迁移点，语言对都还属于欧洲语言之间，声调语言或语音系统距离更远的组合（如中→英）未测；LID 质量、GOP 都是自动指标，“口音压低 73%“与母语者主观口音感知的对应关系只有发音自然度一项盲听支撑。对做多语言 TTS 与声音克隆的人，这篇的双参考加权是可直接借鉴的配方，但先在自己的语言对上复测再谈幅度。

摘要译文：零样本跨语言语音克隆常常把参考说话人的口音带入目标语言。我们提出闭环双参考引导，它将原始参考与一个通过语音转换（VC）构造的可复用的母语锚点配对。这两份参考初始化各自独立的语言模型（LM）状态，引导一条共享的声学轨迹；每个完成的片段随后更新两个状态，使它们生成的历史与已发出的语音保持对齐。锚点构造对每个说话人只运行一次，在线合成使用冻结的 TTS 模型，无需逐话语的 VC。在 20 名留出的法语说话人上，固定设置 λ*=0.33 相对直接克隆将残留的法语 LID 质量降低了 73%，ECAPA 相似度的代价仅为 0.042；相对仅用锚点的克隆，它恢复了 0.155。该方法在留出测试各臂中取得了最低的平均 WER（0.009）和最高的平均 GOP（4.750）。在盲听偏好测试中，母语为英语的听众在发音自然度上更偏好它胜过直接克隆，在说话人身份上更偏好它胜过仅用锚点的克隆和一个 TTS→VC 级联。在线 RTF 大约比级联低 26%（0.59 对 0.80），并且同一设置在无需重新调参的情况下将西班牙语 LID 质量降低了 56%。

简报

1. LoCA：句子级奖励分不清哪一帧错了——用 ASR 对齐把信用分到帧上

2610.28035

面向自回归流匹配 TTS 的强化学习信用分配：用 ASR 文本对齐定位生成语音中的内容错误，把句子级优势（advantage）按帧重新分配，并以参考相对的正负阈值限制过度拟合与过度排斥。在 VoxCPM2 上，多语言 CV3 评测子集的样本加权内容错误相对预训练骨干降低 20.5%、相对 GROW 降低 14.3%，同时说话人相似度提升；在 Seed-TTS-Eval 困难子集上内容准确性也有改善。“奖励太粗"是语音生成 RL 的通病，这套"先定位错误、再分配信用"的做法可迁移到其他带可对齐内容的生成任务；局限是证据集中在一个骨干（VoxCPM2）与内容错误这一类奖励上，韵律、音质类奖励的帧级分配怎么做未覆盖。

2. 普通话字级韵律控制：把韵律标记塞进文本流，不动 TTS 架构

2610.29123

为 LLM 式 TTS 做字级（而非整句级）韵律控制：从原始音频大规模自动抽取细粒度韵律标记（音高、时长、能量、停顿），以词表外 Unicode 符号嵌入文本流，微调现有 TTS 的 LLM 去解读这些标记，架构保持不变；可选的文本 LLM 前端可把自然语言指令翻译成标记序列。在 215 万条普通话话语（5,858 小时）上以 CosyVoice2 为骨干，实现了对字级时长、音高、停顿时长与全局语速的可靠控制，感知质量基本保持。附带发现值得单独记：骨干那个为 ASR 优化的分词器相对重建导向的分词器会削弱韵律变化——作者明确标注为"假设生成级"证据。对做配音、有声书这类逐字抠韵律的场景，这是低侵入的落地方案。

3. StyleStream 2.0：流式语音风格转换延迟砍到 520ms，还能用文字改嗓音

2610.28940

StyleStream 1.0 的续作，修两个短板：延迟与可控性。用少步像素 MeanFlow 模型并借 Self Forcing 思想做自回归反馈微调，把消费级 GPU 上的端到端延迟从约 1 秒降到约 520 毫秒（2 倍加速）且保持转换质量；去掉梅尔频谱上下文、改走紧凑风格嵌入，在同一嵌入空间训练统一的文本条件流匹配模型，同时支持"用自然语言提示设计目标嗓音"与"按指令只改一个属性、其余保持"的语音编辑。实验称在语音风格转换、语音设计、语音编辑三项上目标风格保真度最强，可懂度与未编辑属性保持有竞争力。摘要未给具体指标数值，幅度需查正文；但"流式变声 + 文字可编辑"这个形态对实时语音 Agent 与内容创作都是对的方向。

4. SKAD：先画一张声学证据草图，再做对比解码——治 LALM 推理时"越说越不听音频”

2610.28146

免训练的推理期方法，针对 LALM 长链推理中逐渐从声学证据漂向语言续写模式的问题。直接对普通思维链做音频掩码对比解码往往无效，因为掩码分支缺音频上下文、参考不稳定；SKAD 先构造一份概括问题相关听觉信息的"声学证据草图”，再在音频条件推理分支与仅草图分支之间做对比解码，草图充当共享语义脚手架，使对比信号可靠。在 Qwen2.5-Omni-7B 与 Step-Audio-R1 上、MMAR / MMAU / MMSU 三个基准上平均准确率一致提升，消融显示去掉草图的直接对比解码收益有限甚至为负。摘要未给提升的具体点数；但"对比解码需要一个像样的对照分支"这一方法论提醒，对所有想用对比解码救幻觉的人都成立。
